## 一句话总结

一门讲"用什么手段去测材料"的课。四大板块——光学分析、X 射线分析、表面分析，再加一层贯穿全课的基础——**每个技术都套同一套六段式**：概念、跃迁、谱图特征、装置、分析方法、应用特点。板块本身都不算难，真正的麻烦是**概念多而细碎**；对付它的办法只有一个，就是**把底层原理搞明白**。

## 知识框架

| 板块 | 章 | 主题 |
| --- | --- | --- |
| **引论（共性基础）** | 1 | 光学分析方法引论：电磁辐射、光学分析法分类、光谱仪组成、色散率与分辨率 |
| **原子光谱** | 2 | 原子发射光谱 OES / AES |
| | 3 | 原子吸收光谱 AAS（含原子荧光 AFS） |
| **分子光谱** | 4 | 紫外—可见分光光度法 UV-Vis |
| | 5 | 红外光谱法 IR（含激光拉曼 Raman） |
| **X 射线分析** | 6 | X 射线基础知识 |
| | 7 | X 射线荧光光谱 XRF（WDX / EDX） |
| | 8 | 电子探针微分析 EPMA |
| **表面分析** | 9 | 表面分析技术（表面科学基础） |
| | 10 | 俄歇电子能谱 AES |
| | 11 | X 射线光电子能谱 XPS / ESCA |
| | 12 | 二次离子质谱 SIMS |

**各板块的关系**：分类依据是"跃迁能级 + 激发什么、探测什么"。可以压成一条线——

**外层的用光（原子光谱、分子光谱）→ 内壳层的用 X 射线（XRF、EPMA）→ 最表面的几个原子层用电子和离子（AES、XPS、SIMS）。**

具体说：

- **原子光谱**研究原子**价电子**在基态与激发态之间的跃迁，得到**线光谱**
- **分子光谱**研究分子**电子 + 振动 + 转动**能级的跃迁，得到**带光谱**
- **X 射线光谱**研究原子**内壳层**电子能级的跃迁，谱线少
- **表面分析**只看最表面几个原子层里的电子与离子

**每个技术的六段式**（这是全课最省力的复习结构，也是复习课上老师给的框架）：

**概念 → 跃迁 → 谱图特征 → 装置 → 分析方法 → 应用特点**

**贯穿全课的共性工具**（详见 [复习提纲](复习提纲.md)）：

- **定性定量方法**：对比法、标准曲线法、标准加入法、内标法、相对灵敏度因子法（AES 用 Ag、XPS 用 F 1s）
- **干扰与背景校正**：物理 / 化学 / 电离 / 光谱 / 背景干扰、自吸自蚀；校正手段有扣空白、双谱线、氘灯、塞曼效应、S-H 法
- **表征参量**：色散率、分辨率、灵敏度、检测限
- **常用公式**：Boltzmann 分布、电离度、Lambert-Beer 定律、谱线变宽（自然 / Doppler / Lorentz / 自吸）、跃迁选择定则、莫塞莱定律

## 复习攻略

**第一，平时跟紧节奏，别落下。** 这是本人最想强调的一条。课件加起来近 500 页，一旦落下，补起来很痛苦，而且这门课的概念是一层扣一层的。本人的做法不是课上记笔记，而是**课后把课件从头过一遍**，靠它保证进度不被甩开；发现哪里断了就尽快补回来。

**第二，提前一两个月开始，分三轮**（用的是本人的通用复习方法，见仓库 `通用方法/复习方法.md`）：

1. **第一轮，过知识点。** 按四大板块的顺序捋一遍，每个技术都套那套六段式，重点是搞清楚"它测什么、为什么能测"。
2. **第二轮，做题。** 用老师布置的 21 道作业题（加上课件里的例题）检验自己。做题不是为了刷数量，而是**确认和加深对知识的认识**——做不出来通常说明原理没想通，要回头补。
3. **第三轮，自己建框架。** 合上资料，把各技术按"激发源 / 探测粒子 / 能给出的信息 / 检测限"横向摆一遍，画不出来的地方就是薄弱点。

**第三，以复习课课件为纲。** 复习课上老师给的课件基本就是重点范围，里面把每个技术按六段式重新列了一遍。本人的复习以这份课件为主，想不起来的地方再回课件正文。每年的安排可能调整，**最终以当年通知为准**。

**第四，横向对比比纵向精读更有用。** 这门课单看每个技术都不难，难的是把十几个技术区分开——建议自己动手做一张对比表。

## 重点与难点

- **六段式本身就是考点**：老师复习课给的框架就是"概念 → 跃迁 → 谱图特征 → 装置 → 分析方法 → 应用特点"，按这个顺序逐项过，基本不会漏。
- **作业题与期末计算题很相似**，那 21 道题一定要做完、做懂，这是这门课性价比最高的一件事。
- **概念细碎是最容易翻车的地方**：板块内部的技术很容易记混，比如 XRF 与 EPMA 的激发源和探测信号、AES 与 XPS 的谱线标识与峰位判读。
- **计算集中在几类题**：谱线变宽（自然宽度、多普勒变宽）、Boltzmann 分布算粒子数比、电离度、标准加入法求浓度、色散与分辨本领、俄歇电子能量、光电子动能、磁质谱公式、SIMS 的质量分辨要求。

## 常见坑

1. **平时不跟、指望考前突击。** 课件近 500 页，概念一层扣一层，落下之后再补的成本远高于平时每天过一点。
2. **把概念当成孤立的词条硬背。** 每个技术背后的原理就那么几条；想通"仪器为什么这样设计、谱图为什么长这样"，细节是能推出来的。
3. **不做那 21 道作业题。** 它们和期末计算题很像，是性价比最高的投入。
4. **只纵向过、不横向比。** 这门课真正的难点是区分技术，横向对比表一定要自己动手做一遍。
