# 第一章 材料科学概论

## 1.1 五大基础材料

材料品种数以千万计，但主要分为五类。其中前三类是基础材料，后两类是经过特殊加工、面向现代生活需求的基础材料。

### 金属材料

- **定义**：以金属元素为主，通过冶炼方式制成的晶体材料。
- **键合方式**：金属键。
- **特点**：强度高、延展性好、导电导热；但易腐蚀、不透明。
- **分类**：黑色金属、有色金属。

### 陶瓷材料

- **定义**：由非金属元素，或金属元素与非金属元素组成，采用烧结、合成等工艺制备的无机非金属材料。
- **键合方式**：**【补充】** 普通陶瓷以离子键为主；先进陶瓷多为离子键与共价键的混合（结构陶瓷中常见共价键为主）。
- **特点**：硬度高、耐高温、绝缘；但脆性大、难加工。
- **分类**：普通陶瓷、先进陶瓷。
- **【易错】** 不要记成"普通陶瓷是离子键、先进陶瓷是共价键"。先进陶瓷的键合是混合型的，功能陶瓷（如 CaF₂、ZnS、GaAs 等）与结构陶瓷（如 Si₃N₄、TiB₂ 等）都属于先进陶瓷。

### 聚合物材料

- **定义**：以碳、氢元素为主的结构单元，通过共价键重复连接而成的高分子化合物。
- **键合方式**：共价键（分子链之间为范德华力或氢键）。
- **特点**：轻质、耐蚀、绝缘、易加工；但强度低、耐热性差。
- **分类**：塑料（热固性树脂、热塑性塑料）、纤维、橡胶、涂料。

### 复合材料

- **定义**：由两种以上材料组成，采用特殊加工制成、面向工程应用的组合材料。
- **键合方式**：**【补充】** 通常同时存在多种键合方式（不是单一类型），因此性能可以在较大范围内设计。
- **特点**：比强度高、比模量高、性能可设计；但界面较弱。
- **分类**：结构复合材料、功能复合材料。
- **举例**：混凝土、坦克装甲、玻璃钢（玻璃纤维增强环氧树脂）。

### 半导体材料

- **定义**：以 Si、Ge 等元素为主，电性能可控可调的单晶、多晶或非晶材料。
- **键合方式**：共价键。
- **特点**：导电性介于导体与绝缘体之间；化学纯度与表面加工精度要求极高；性能易受成分、尺寸、工艺影响。
- **分类**：元素半导体、化合物半导体、第三代半导体。

**【考点】** 五大材料的"定义 + 特点 + 分类 + 举例"是全章最重要的内容，简答题常直接从这里出。

## 1.2 材料科学与材料科学与工程

| | 研究对象 |
| --- | --- |
| 材料科学 | 材料的成分、结构、性质 |

**【易错】** 两者不是并列关系，材料科学与工程多出的正是"加工工艺 → 性能 → 应用"这一整条链路。

## 1.3 材料科学与工程四要素

1. 成分 / 结构
2. 性质
3. 合成 / 制备
4. 性能

四要素构成一个四面体，任一要素改变都会牵动其他三个。

## 1.4 纳米材料

- **定义**：**【补充】** 在三维空间中**至少有一个维度处于 1–100 nm 范围**的材料（只写"尺寸小于 100 nm 的微粒"会漏掉纳米薄膜、纳米块体）。
- **四大效应**：小尺寸效应、表面效应、量子尺寸效应、量子隧道效应。
- **应用举例**：钙钛矿、碳纳米管。

# 第二章 材料结构的基础知识

## 2.1 材料的四级结构

从微观到宏观依次是：原子结构 → 原子键合 → 原子排列 → 显微组织。

| 层级 | 决定什么 | 影响的性能 |
| --- | --- | --- |
| 原子结构 | 原子间结合方式 | 原子半径、熔点、热膨胀系数 |
| 原子键合 | 结合力的大小 | 物理性能与力学性能 |
| 原子排列 | 材料的形态 | 导电性、导热性、透明性 |
| 显微组织 | 可通过加工工艺调整 | 强度、塑性、变形能力 |

**【补充】** 材料结构一般分为四个层次：原子结构（电子结构）、原子的空间排列（晶体/非晶体）、显微组织（相组成与晶粒形态）、宏观组织。加工工艺主要作用在"显微组织"这一层，这也是工艺能改变性能的原因。

## 2.2 原子物理基础

需要掌握：

- **四个量子数**（要会写、会说明物理意义）
- **Pauli 不相容原理**
- **Hund 规则**
- **电子排布式**——注意区分"填充过程"与"最终排布式"

**【补充】** 电子排布要按能级顺序填充（1s → 2s → 2p → 3s → 3p → 4s → 3d → …），但书写排布式时按主量子数归并。例如 Fe（Z=26）的排布式为 1s²2s²2p⁶3s²3p⁶3d⁶4s²。这一处是常考的"会填充但不等于会书写"。

**【考点】** 材料科学发展史不考；海森堡方程、薛定谔方程不要求，但量子数、Pauli、Hund、电子排布式要会。

## 2.3 原子价、电负性、周期律

- **原子价**：原子与其他原子结合的能力。
- **电负性**：原子在化合物中吸引电子的能力。电负性差越大，键的离子性越强。
- **周期律**：原子半径、电离能、电负性随原子序数呈周期性变化，直接影响材料的键合与性能。

## 2.4 结合键

### 一次键（化学键）

| 键型 | 定义 | 特点 |
| --- | --- | --- |
| 离子键 | 失电子成为正离子、得电子成为负离子，二者之间的库仑引力 | 键能高、无方向性、硬而脆、绝缘 |
| 共价键 | 相邻原子共用外层电子对，形成稳定满壳层 | 键能高、有方向性与饱和性 |
| 金属键 | 正离子与自由电子之间的相互吸引 | 无方向性、导电导热、延展性好 |

### 二次键（物理键）

**范德华键**——分子间由电偶极矩产生的静电吸引力，包括三种：

| 类型 | 产生原因 |
| --- | --- |
| 取向力 | 极性分子间固有电偶极矩之间的吸引 |
| 诱导力 | 非极性分子在电场作用下被诱导出电偶极矩 |
| 色散力 | 分子内瞬时电偶极矩导致的吸引 |

**氢键**——氢原子特有的一种分子间相互作用力。

## 2.5 结合能与材料性能

键强度排序：

**共价键 ≈ 离子键 > 金属键 >> 范德华键**

用途：解释熔点高低、硬度大小、热膨胀系数、弹性模量等差异——键越强，熔点越高、硬度越大、热膨胀系数越小。

**【补充】** 结合能（键能）数值上等于把原子从平衡位置拉开到无穷远所需的能量。范德华键的键能通常只有几十 kJ/mol，比一次键低一个数量级，这解释了为什么塑料的熔点与强度远低于金属和陶瓷。

**【考点】** 常以"比较两种材料/两种分子间作用力的大小，并解释某种现象"的形式考简答。

## 2.6 原子排列方式

- **晶态**：质点在三维空间周期性重复排列。
- **非晶态**：不呈现长程有序（可能微区有规则排列）。

单相与多相属于显微组织层面的概念，了解即可。

# 第三章 固体材料的晶体学基础

> 本章是全课程内容最多、计算最集中的一章，后续课程（材料物理、材料结构与性能等）使用频率也最高。

## 3.1 晶体与非晶体

分类依据：质点排列方式与空间分布的有序程度。

| | 晶体 | 非晶体 |
| --- | --- | --- |
| 质点排列 | 三维周期性重复对称排列 | 长程无序 |
| 外形 | 均匀对称的几何外形 | 无固定外形 |
| 性能 | 各向异性 | 各向同性 |
| 熔化 | 熔点确定 | 熔点不固定（软化区间） |
| X 射线 | 可发生衍射 | 无衍射条纹 |
| 能量 | 相同热力学条件下内能最小 | — |

## 3.2 晶体结构、空间点阵、晶格与晶胞

这四个概念常被混淆，要能说清区别：

| 概念 | 含义 |
| --- | --- |
| 晶体结构 | 组成晶体的质点在三维空间作周期性重复对称的排列结构 |
| 空间点阵 | 几何点在三维空间作周期性重复排列组成的三维阵列 |
| 阵点 | 构成空间点阵的点 |
| 晶格 | 在想象的空间点阵中，用平行线段连接阵点形成的空间骨架 |
| 晶胞 | 从晶格中取出的代表性六面体，重复堆积即可构成完整点阵 |

**晶胞选取原则**：具有对称性、尽可能有直角、体积最小。

**晶胞分类**：简单晶胞（仅八个顶点有阵点）、复杂晶胞（体心、面心等处还有阵点）。

**点阵参数**：三条边长 a、b、c 及三个夹角 α、β、γ。

## 3.3 晶系与布拉菲点阵

7 种晶系、14 种布拉菲点阵：

| 晶系 | 特点 | 点阵种类 |
| --- | --- | --- |
| 立方 | 正方体 | 简单立方、体心立方、面心立方 |
| 正方（四方） | 长方体且底面为正方形 | 简单正方、体心正方 |
| 正交 | 长宽高各不相等，且互相垂直 | 简单正交、底心正交、体心正交、面心正交 |
| 六方 | 底面为正六边形 | 简单六方 |
| 菱方 | 三边相等、三角相等但不为 90° | 简单菱方 |
| 单斜 | 三边不等，有一个角不为 90° | 简单单斜、底心单斜 |
| 三斜 | 三边不等、三角均不为 90° | 简单三斜 |

**常见金属的晶系**

| 结构 | 典型元素/相 |
| --- | --- |
| 体心立方 BCC | α-Fe（铁素体）、Cr、V、Mn、W、Nb、Mo |
| 面心立方 FCC | γ-Fe（奥氏体）、Al、Cu、Ni |
| 密排六方 HCP | Be、Mg、Zn、Ti、Cd |

## 3.4 晶向指数与晶面指数

### 晶向指数 [uvw]

1. 建立右手坐标系，以晶胞某顶点为原点；
2. 求该方向上两点矢量在各坐标轴上的分量；
3. 化为最小整数比；
4. 用方括号 **[uvw]** 表示；族用尖括号 **<uvw>**。

### 晶面指数 (hkl)

1. 建立右手坐标系，**待定晶面不能过原点**（过原点则平移）；
2. 求晶面在三个坐标轴上的截距；
3. 取截距的倒数；
4. 化为最小整数比；
5. 用圆括号 **(hkl)** 表示；族用花括号 **{hkl}**。

### 六方晶系的四轴指数

采用四轴 a₁、a₂、a₃、c，其中 a₁、a₂、a₃ 在同一底面内互成 120°，c 轴与底面相垂直。

- 晶面指数用 **(hkil)** 表示，其中 **i = −(h + k)**；
- 晶向指数用 **[uvtw]** 表示，同样满足 **t = −(u + v)**。

**【补充】** 之所以要加这个 i 轴，是因为用三轴指数描述六方晶系时，晶体学上等价的晶面会得到不同的指数形式，看不出对称性；四轴指数能直接体现六方对称。

### 【易错】同指数晶向与晶面垂直，只在立方晶系成立

"具有相同指数的晶向与晶面必定相互垂直"，例如 [100] ⊥ (100)——**这个结论只在立方晶系中成立**。六方、正交等晶系不能直接套用。

**【考点】** 晶向指数与晶面指数的书写、画图、区分，以及晶向族与晶面族的判断，是每年必考的内容。

## 3.5 晶带与晶面间距

### 晶带与晶带定律

- **晶带**：空间点阵中平行于某一轴向的所有晶面的集合。
- **晶带定律**：属于晶向 [uvw] 晶带的晶面 (hkl) 必满足

$$hu + kv + lw = 0$$

原理：同一晶带所有晶面的法线都与晶带轴垂直。

### 【补充】晶面间距公式

晶面间距 d 指相邻两个平行晶面之间的垂直距离。

| 晶系 | 公式 |
| --- | --- |
| 立方 | $\dfrac{1}{d^2} = \dfrac{h^2+k^2+l^2}{a^2}$ |
| 正方 | $\dfrac{1}{d^2} = \dfrac{h^2+k^2}{a^2} + \dfrac{l^2}{c^2}$ |
| 正交 | $\dfrac{1}{d^2} = \dfrac{h^2}{a^2} + \dfrac{k^2}{b^2} + \dfrac{l^2}{c^2}$ |
| 六方 | $\dfrac{1}{d^2} = \dfrac{4}{3}\cdot\dfrac{h^2+hk+k^2}{a^2} + \dfrac{l^2}{c^2}$ |

使用步骤：先由点阵参数判断所属晶系，再选公式。低指数晶面的晶面间距较大。

**【易错】** 六方晶系这一个是记忆难点，注意它与立方系结构的区别：分子上是 h² + hk + k²（有一个交叉项 hk），且前面带 4/3。

### Bragg 定律

$$2d\sin\theta = n\lambda$$

其中 d 为晶面间距，θ 为入射角（与晶面的夹角），λ 为波长，n 为衍射级数。

**【考点】** Bragg 定律不要求计算，但要知道各项含义。

## 3.6 晶胞特征参数

**【补充】三种典型结构的完整参数表（建议背下来）**

| 参数 | 简单立方 SC | 体心立方 BCC | 面心立方 FCC | 密排六方 HCP |
| --- | --- | --- | --- | --- |
| 晶胞原子数 | 1 | 2 | 4 | 6 |
| 原子半径与点阵参数关系 | r = a/2 | r = √3a/4 | r = √2a/4 | r = a/2 |
| 配位数 | 6 | 8 | 12 | 12 |
| 致密度 | 0.52 | 0.68 | 0.74 | 0.74 |

**常用计算式**

- 致密度 $K = \dfrac{n \cdot \frac{4}{3}\pi r^3}{V_{晶胞}}$
- 原子体密度 $\rho = \dfrac{n \cdot A}{V_{晶胞} \cdot N_A}$（n 为晶胞内原子数，A 为摩尔质量，N_A 为阿伏伽德罗常数）

**【易错】** 给定元素要能先判断晶胞类型，再计算。单位换算是高频失分点：a 的单位常给 pm 或 Å，密度常用 g/cm³，1 Å = 0.1 nm = 10⁻¹⁰ m。

## 3.7 密堆结构的间隙

间隙按构成的多面体顶点数分类：四面体间隙、八面体间隙。

间隙半径的定义：在构成晶胞的原子半径确定后，间隙内能填入的球的最大半径。

**【补充】间隙数目与尺寸（与课件一致）**

| 晶胞 | 八面体间隙数 | 四面体间隙数 | 八面体间隙半径 | 四面体间隙半径 |
| --- | --- | --- | --- | --- |
| FCC | 4 | 8 | 0.414R | 0.225R |
| BCC | 6 | 12 | 0.155R | 0.291R |
| HCP | 6 | 12 | 0.414R | 0.225R |

（R 为基体原子半径。HCP 的间隙尺寸规定与 FCC 相同。）

**【易错】BCC 是反例**：BCC 的八面体间隙半径（0.155R）反而**小于**四面体间隙半径（0.291R），与 FCC、HCP 的规律相反。另外 BCC 的八面体间隙是不对称的——沿棱方向较"扁"。这是常考陷阱。

## 3.8 合金的晶体结构

### 基本概念

- **合金**：两种或两种以上金属元素，或金属元素与非金属元素组成的、具有金属特性的物质。
- **相**：合金中具有相同的组成、结构与性质，并以相界面相互分开的均匀组成部分。

### 固溶体

- **定义**：溶质原子溶于固态溶剂中，并保持溶剂元素晶格类型的合金。
- **分类**：
  - 置换固溶体——溶质原子占据溶剂晶格的某些节点位置（按有序性可再分有序固溶体与无序固溶体）；
  - 间隙固溶体——原子半径小于 0.1 nm 的非金属元素（H、B、C、N、O 等）处于溶剂晶格的间隙位置。
- **溶解度**：一定条件下溶质原子溶入固溶体的极限浓度。
  - 分类：有限固溶体（溶解度 < 100%）、无限固溶体（任意比例互溶）。
  - **影响因素**：原子大小、晶格类型、电化学性质（电负性）、电子浓度。

### 中间相

- **定义**：两组元形成的合金中，溶质含量超过溶解度时产生的、成分处于两种最大溶解度之间的新相。
- **性质**：化合物或以化合物为基的固溶体，晶体结构不同于任一组成元素。
- **分类**：正常价化合物、电子化合物、尺寸因素化合物。

## 3.9 陶瓷与离子晶体

### 陶瓷的结构

- **普通陶瓷的显微组织**：晶体相、玻璃相、气孔。
- **先进陶瓷**：共价晶体或离子晶体，化学键多为离子键与共价键的混合。
- **分类**：普通陶瓷、先进陶瓷（结构陶瓷、功能陶瓷）。

### 离子晶体

- **离子半径**：原子核到最外层电子的平均距离。
- **离子晶体的平均距离**：一对正负离子的接触半径之和。
- **配位数**：与某一离子相邻的异号离子的数目。确定方法：先确定结构，再画图数。

### 【补充】Pauling 规则

1. **第一规则**：负离子通常堆积成骨架，正离子居于负离子构成的间隙位置，形成负离子配位多面体。（多面体的形状由正负离子半径比决定。）
2. **第二规则**（电价规则）：每个负离子的电价 Z₋ 等于或接近与之邻接的各正离子静电强度 S 的总和，其中正离子的静电强度 $S = \dfrac{Z_+}{\mathrm{CN}}$（Z₊ 为该正离子电价，CN 为其配位数）。
3. **第三规则**：负离子配位多面体的稳定性会因共用顶点、共用棱、共用面而依次削弱。

### 【补充】典型二元离子晶体结构

| 类型 | 结构描述 | 举例 |
| --- | --- | --- |
| NaCl 型 | 负离子构成面心立方，正离子占据其八面体间隙 | MgO、CaO、BaO |
| CsCl 型 | 负离子构成简单立方，正离子占据体心 | CsBr、CsI |
| 立方 ZnS 型 | 负离子构成面心立方，正离子交错占据一半四面体间隙 | GaAs、AlP、InSb |
| 六方 ZnS 型 | 六方结构，正负离子配位数均为 4 | BeO、ZnO、AlN、AgI |
| **CaF₂ 型（AB₂ 型）** | **正离子（Ca²⁺）构成面心立方点阵，8 个负离子（F⁻）位于晶胞内 8 个四面体间隙的中心位置** | ZrO₂ |
| 金红石 TiO₂ 型 | AB₂ 型 | TiO₂ |
| A₂O₃ 型 | — | α-Al₂O₃、α-Fe₂O₃、Ti₂O₃ |
| ABO₃ 型 | 钙钛矿型 | 钙钛矿类、含钛氧的离子晶体 |
| AB₂O₄ 型 | 尖晶石型 | — |

**【易错】** CaF₂ 型不要记反：是**正离子**构成面心立方点阵，不是负离子。这类"谁构成骨架、谁填间隙"的问题在表中逐条核对一遍最省事。

## 3.10 共价晶体与高分子晶体

### 共价晶体

- **定义**：同种元素或异种元素的原子以共价键形成的无限大分子。
- **8−N 法则**：共价键结构中，原子的配位数 = 8 − N，N 为该原子的价电子数。
- **典型结构**：金刚石型（配位数 4）、硫化锌型、二氧化硅型（与金刚石型类似）。

### 高分子的晶体结构

- **近程结构**：结构单元的化学组成、空间排列、键接方式、支化度。
- **远程结构**：高分子链的长度与形态、链的柔顺性、不同环境下的链构象。
- **3C（三个关键指标）**：
  - **构造（Constitution）**：链的原子种类与排列、取代基与端基种类、单体单元排列顺序、支链类型与长度；
  - **构型（Configuration）**：单体单元中原子或取代基在空间中的相对位置与键合方式（改变需断键）；
  - **构象（Conformation）**：大分子链的柔顺性、几何形态（改变只需绕单键旋转）。

**【易错】** 构型与构象的区别：构型改变要断化学键，构象改变只是单键旋转。这是常考的辨析点。

# 第四章 固体材料的晶体缺陷

## 4.1 缺陷的分类

| 类型 | 维度 | 典型形式 |
| --- | --- | --- |
| 电子缺陷 | — | — |
| 点缺陷 | 零维 | 空位、间隙原子、异类原子 |
| 线缺陷 | 一维 | 位错 |
| 面缺陷 | 二维 | 晶界、孪晶界面、堆垛层错 |
| 体缺陷 | 三维 | 空洞、气泡、包藏杂质、沉淀 |

**【考点】** 点缺陷与线缺陷考得最多，面缺陷以简答为主。

## 4.2 点缺陷

**定义**：三维尺度上不大于几个原子大小的微缺陷。

### 三类基本形式

| 形式 | 含义 |
| --- | --- |
| 空位 | 点阵晶格中没有原子的结点，由原子的热振动引起 |
| 间隙原子 | 位于点阵晶格间隙处的原子 |
| 异类原子（置换原子） | 占据点阵晶格节点的其他原子 |

空位和间隙原子均由原子的热振动引起。适量空位有益于材料的加工成型与改性；通过掺杂引入异类原子可改善力学与物理性能。

### Schottky 缺陷与 Frenkel 缺陷

| 缺陷 | 特征 |
| --- | --- |
| Schottky 缺陷 | 只形成空位，**没有等量的间隙原子**（离子晶体中是成对的空位，保持电中性） |
| Frenkel 缺陷 | 形成空位的同时形成**等量的间隙原子**（原子从节点"移位"到间隙） |

**【易错】** 这两个名字对应的图最容易记反。判断口诀：Frenkel 有"移位"，所以有空位也有间隙原子；Schottky 只有空位。

### 点缺陷对性能的影响

1. **晶格畸变**：缺陷周围产生附加弹性应力场，体系内能升高；
2. **力学与电学性能**：固溶体因附加弹性应力场而强度上升，电阻率增大；
3. **体积与密度**：产生空位使体积增大、密度下降；
4. **热学性能**：需要向晶体提供附加能量，因此比热容增加。

## 4.3 线缺陷——位错

**定义**：在二维尺度上尺寸极小、在三维尺度上延伸很长的一种缺陷。

**【补充】位错的来源**：主要产生于凝固结晶时的原子错排；此外，晶体中其他缺陷产生的内应力以及材料的塑性变形也会形成位错。

**【易错】** 不能记成"位错只来自结晶过程"，塑性变形是位错的重要来源。

### 位错的两种基本类型

| | 刃型位错 | 螺型位错 |
| --- | --- | --- |
| 关键概念 | 位错线、滑移面、额外半原子面 | 位错线、滑移面 |
| 产生原因 | 晶体局部滑移（滑移方向与位错线**垂直**） | 切应力作用（滑移方向与位错线**平行**） |
| 运动方式 | 滑移 + 攀移 | 一般只有滑移（可交滑移），无攀移 |

攀移的两种形式：半原子面向上运动为正攀移，向下为负攀移。

实际晶体中的位错大多是刃型与螺型的**混合位错**。

### Burgers 回路与 Burgers 矢量

- 在晶体中围绕位错线做一个闭合回路（右旋回路），由于位错的存在，回路不能真正闭合，闭合所需的矢量就是 **Burgers 矢量 b**。
- Burgers 矢量的方向即为滑移方向，可借助晶向指数写出其 Miller 指数并计算长度。

**【补充】常见结构的 Burgers 矢量（了解即可，课件未要求推导）**

| 结构 | Burgers 矢量 | 长度 |
| --- | --- | --- |
| FCC | b = (a/2)⟨110⟩ | \|b\| = a/√2 ≈ 0.707a |
| BCC | b = (a/2)⟨111⟩ | \|b\| = (√3/2)a ≈ 0.866a |
| HCP | b = (a/3)⟨11−20⟩ | \|b\| = a |

### 位错对材料的影响

1. 解释了**实际强度远低于理论强度**的原因（晶体中存在易滑移的位错）；
2. 赋予了金属良好的**延展性**；
3. 通过干预位错运动实现**固溶强化**，提高金属与合金的力学性能；
4. 塑性变形过程中位错密度增加，位错间交互作用增强，运动变困难，晶体逐渐硬化（**加工硬化**）；
5. 为含裂纹材料的疲劳开裂与断裂、材料的损伤、各种强化机制提供理论基础。

### 位错的实验观测方法

表面法（蚀坑法）、缀饰法、透射电镜（TEM）观测法、X 射线衍射法。

## 4.4 面缺陷

**定义**：在一个方向上尺寸极小，而在另外两个方向上尺寸很大的缺陷。

### 晶体外表面

表面原子的配位数比内部少，偏离正常位置，产生晶格畸变，导致能量升高。

### 晶界

金属与合金通常为多晶体，由晶体结构相同但位向不同的晶粒组成，晶粒间的界面称为晶界。

| 类型 | 位向差 | 结构特征 |
| --- | --- | --- |
| 小角度晶界 | < 10° | 由多个位错（位错阵列）构成，对滑移的阻碍作用弱于大角度晶界 |
| 大角度晶界 | > 10° | 结构复杂，晶界处原子排列不规则 |

**【补充】** 晶粒内部位向差极小的亚结构之间的界面称为**亚晶界**，亚晶界属于小角度晶界。

**晶界的特性**（高频简答题）

1. 若能降低界面能的异类原子存在，会向晶界偏聚，称为**内吸附现象**；
2. 晶界上原子能量较高、缺陷较多，**扩散速度比晶粒内部快得多**；
3. 常温下大角度晶界阻碍位错运动，因此晶粒越细、单位体积内晶界面积越大，强度和硬度越高（**细晶强化**）；
4. 晶界比晶粒内部更容易氧化和腐蚀；
5. 由于能量高、原子排列紊乱，相变时优先在母相晶界上形核。

### 孪晶界

- **孪晶**：相邻两个晶粒中的原子沿一个公共晶面构成镜面对称的位向关系；
- **孪晶界**：孪晶之间的界面。

### 相界

多相组织中，具有不同晶体结构的两相之间的分界面。分类：**共格界面、半共格界面、非共格界面**。

### 堆垛层错

晶体中密排原子面在堆垛过程中，堆垛顺序发生错误或偏差，破坏了晶体的周期性排列；会使晶体能量升高。

## 4.5 体缺陷

尺寸可与晶体或晶粒尺寸相当的缺陷，如空洞、气泡、包藏杂质、沉淀。

# 第五章 材料热力学与相图

> 本章是相图计算题的来源，杠杆定律与铁碳相图是必考内容。

## 5.1 相与相图

- **相**：具有相同的化学成分、晶体结构与性质，并以界面与其他部分隔开的匀质材料。
- **相图**：表示在温度、压力、成分等不同组合下，相的状态及转变的图像。

**二元相图的读图方法**：横坐标是成分（质量分数或摩尔分数），纵坐标是温度；左右两端分别对应两个纯组元，其熔点由相图两端在纵轴上的截距给出。

## 5.2 Gibbs 相律

$$F = C - P + 2$$

其中 F 为自由度数，C 为组元数，P 为平衡共存的相数。式中"2"对应温度和压力两个变量。**凝聚系统（固液相变，压力影响可忽略）常用**：

$$F = C - P + 1$$

**【补充】二元系（C = 2）的三种情形，是最实用的记法与考点**

| 情形 | P | F（恒压） | 物理含义 |
| --- | --- | --- | --- |
| 单相区 | 1 | 2 | 温度与成分都可独立变化 |
| 两相区 | 2 | 1 | 温度一定，两相成分就随之确定 |
| 三相共存 | 3 | 0 | 温度和三相成分都固定 → 相图上是一条水平线 |

**【易错】** 相图上的水平线（共晶线、共析线、包晶线）之所以是水平的，正是相律推出的结果。理解这一点，三条水平线的反应式就不会记混。

## 5.3 二元合金相图的类型

### 匀晶相图

两组元在**液态与固态下都能无限互溶**。L 为液相，α 为固相；两相共存时，随温度变化，两相中各组元的含量也同步变化。

### 共晶相图

两组元在液态下无限互溶、固态下有限互溶，并发生共晶反应。

- **共晶反应**：恒温下液相直接分解为两种不同的固相，L → α + β；
- 可能出现的相区：L、L+α、L+β、α+β、α、β；
- α、β 均为有限固溶体；
- 可能出现**二次析出**：α 冷却过程中析出 β。

### 包晶相图

两组元在液态下无限互溶，固态下有限互溶或不互溶，并发生包晶反应；典型例子是 Fe-Fe₃C、Pt-Ag。

- **包晶反应**：一定温度下液相与固相相互作用生成另一固相，新相在液固交界面上形核长大，三相共存。

### 其他类型

熔晶反应、合晶反应等，了解即可。

## 5.4 杠杆定律（必考计算）

**用途**：在**两相区**内计算两相各自的相对量。

**【补充】公式与步骤**

设合金总成分为 C₀，两相成分分别为 C_α、C_L：

$$W_\alpha = \frac{C_0 - C_L}{C_\alpha - C_L}, \qquad W_L = \frac{C_\alpha - C_0}{C_\alpha - C_L}$$

步骤：

1. 通过合金成分点作水平线，与两相区分界线交于两点，读出两个相的成分；
2. 用"**对面的臂长**除以总臂长"求该相的比例（杠杆原理）；
3. 两相比例之和为 1，用于校验。

**【易错】** 杠杆定律只适用于**两相区**。单相区没有意义；三相共存时三个相的比例不能由杠杆定律确定。

**学习建议**：这部分内容课件写得比较简略，直接找相图题目练习最有效，做几道题就能理解并记住步骤。

## 5.5 铁碳合金相图

### 基本划分

| 分类 | 含碳量 |
| --- | --- |
| 工业纯铁 | < 0.0218% |
| 钢 | 0.0218% ~ 2.11% |
| 铸铁 | > 2.11% |

相图左端组元为 Fe，右端为 Fe₃C，从左向右对应含碳量上升。

### 四个基本相

| 名称 | 符号 | 说明 |
| --- | --- | --- |
| 铁素体 | F 或 α | 碳溶于 α-Fe 形成的间隙固溶体，结构为 BCC |
| 奥氏体 | A 或 γ | 碳溶于 γ-Fe 形成的间隙固溶体，结构为 FCC |
| 渗碳体 | Fe₃C 或 Cm | 铁碳化合物，硬而脆的强化相 |
| 珠光体 | P | 片状铁素体与片状渗碳体交替叠合，即 α + Fe₃C |

### 【补充】关键点的成分与温度

| 关键点 | 含义 | 成分 / 温度 |
| --- | --- | --- |
| J | 包晶点 | 0.17%C，1495℃ |
| E | 碳在奥氏体中的最大溶解度 | 2.11%C，1148℃ |
| C | 共晶点 | 4.3%C，1148℃ |
| S | 共析点 | 0.77%C，727℃ |

### 关键线与三个恒温反应

| 线 | 名称 | 反应 | 温度 |
| --- | --- | --- | --- |
| HJB | 包晶反应线 | L + δ → γ | 1495℃ |
| ECF | 共晶反应线 | L → γ + Fe₃C（产物为莱氏体） | 1148℃ |
| PSK | 共析反应线 | γ → α + Fe₃C（产物为珠光体） | 727℃ |
| GS（A₃ 线） | 奥氏体冷却时开始析出铁素体 | — | — |
| ES（Acm 线） | 碳在奥氏体中的固溶度曲线 | — | — |
| PQ 线 | 碳在铁素体中的固溶度曲线 | — | — |

**【补充】** 共晶产物**莱氏体**在高温下是 γ + Fe₃C，冷却到室温后转变为珠光体 + 渗碳体。

**【易错】** 三个恒温反应极易混淆，按"**包晶是两相变一相，共晶是一相变两相，共析也是由一相变两相但发生在固态**"来区分。

### 含碳量对性能的影响

**力学性能**

- 铁素体是软韧相，渗碳体是硬脆强化相；
- 渗碳体含量越高，硬度和强度越高，塑性与韧性越低；
- 渗碳体分布在晶界上或作为基底时，塑性、韧性、抗拉强度降低；
- 含碳量大于 1.0% 时渗碳体出现网状分布，钢的强度下降而硬度继续上升。

**工艺性能**

| 性能 | 规律 |
| --- | --- |
| 切削加工性 | 中碳钢塑性适中、硬度约 HB200 时较好；含碳过高或过低都不利 |
| 铸造性 | 接近共晶成分的铸铁结晶温度低、流动性好；结晶温度区间越宽越易缩孔与偏析 |
| 焊接性 | 塑性越好越易焊接，低碳钢优于高碳钢 |
| 热处理性 | 不同含碳量需制定不同的热处理工艺参数 |

## 5.6 Gibbs 自由能与化学位

$$G = H - TS$$

- **化学位**：温度、压力不变时，某组元增加 1 mol 引起的吉布斯自由能变化，又称偏摩尔吉布斯自由能；
- 物理含义：体现某组元从某相中逸出的本领，是一种势能函数；
- 扩散的主要驱动力就是化学位梯度（见第七章）。

# 第六章 材料的凝固与结晶

## 6.1 基本定义

- **凝固**：物质从液态冷却成固态的相变过程。
- **结晶**：液态物质冷却时凝固成晶体。

## 6.2 结晶的分类

| 类型 | 含义 |
| --- | --- |
| 一次结晶 | 金属与合金从液态转变为晶体 |
| 二次结晶 | 金属冷却过程中从一种晶体结构转变为另一种晶体结构 |

## 6.3 金属结晶的基本过程

**微观过程**（要能按顺序复述）

1. 液态金属冷却至熔点以下某一温度，保温一段时间后产生**晶胚**；
2. 保温孕育期内，部分晶胚长大成为**晶核**，晶核长大的同时不断涌现新的晶核；
3. 晶核长大成为**晶粒**，液态金属逐渐减少；
4. 长大的晶粒彼此相遇，液态金属耗尽，结晶完毕。

一句话概括：**冷却至熔点以下并保温 → 晶胚 → 晶核 → 晶粒 → 液耗尽，结晶完成**。结晶是成核与长大交替进行的过程；若全程只有一个晶核长大，则得到单晶体。

**宏观特征**：液态金属结晶时的实际温度总低于熔点，差值称为**过冷度 ΔT**。过冷度越大，形核数目越多，晶粒越细小，材料性能越好——控制过冷度就是控制晶粒大小。

## 6.4 金属结晶的条件

| 条件 | 内容 |
| --- | --- |
| 热力学条件 | 过冷度——提供相变的驱动力 |
| 结构条件 | 结构起伏（含能量起伏）——产生晶核的基础 |

- **结构起伏**：液态金属中近程有序结构短暂出现又消失的现象，其尺寸与温度有关（先升后降）。
- **晶胚**：过冷液态金属中短程规则排列、尺寸较大的原子有序排列部分，具有尺寸极限。
- **晶核**：晶胚尺寸大于等于**临界尺寸**时才称为晶核。

## 6.5 晶核的形成

| | 均匀形核 | 非均匀形核 |
| --- | --- | --- |
| 定义 | 依靠液态金属自身能量变化获得驱动力，由晶胚直接成核 | 晶胚依附在其他物质（杂质、容器壁）表面形核 |
| 形核功 | 大 | 小（杂质提供了现成表面，降低了表面能） |
| 所需过冷度 | 大 | 小 |

实际结晶过程中以**非均匀形核**为主。

### 【补充】均匀形核的核心公式

形核时自由能变化由体积自由能降低与表面能升高两项组成：

$$\Delta G = -V\Delta G_V + A\gamma$$

**临界半径**

$$r^* = -\frac{2\gamma}{\Delta G_V} = \frac{2\gamma T_m}{L_m \Delta T}$$

**形核功**

$$\Delta G^* = \frac{16\pi\gamma^3}{3\Delta G_V^2} = \frac{16\pi\gamma^3 T_m^2}{3L_m^2 \Delta T^2}$$

其中 γ 为表面能，ΔG_V 为单位体积自由能变化，T_m 为熔点，L_m 为熔化潜热，ΔT 为过冷度。

**【易错】** 临界形核功恰好等于临界晶核表面能的 **1/3**，即 ΔG* = (1/3)·A*·γ。这句结论常用于简答题，也说明形核所需的能量起伏只需补充表面能的 1/3。同时注意：过冷度越大，临界半径与形核功越小，形核越容易。

### 形核率及其影响因素

$$I = C\exp\left(-\frac{\Delta G^*}{kT}\right)\exp\left(-\frac{Q}{kT}\right)$$

Q 为原子越过液固相界面的扩散激活能。过冷度增大时，形核功项使形核率上升，而扩散项使形核率下降，两者竞争，因此形核率随过冷度呈先增后减的规律。

**非均匀形核率的影响因素**

| 因素 | 规律 |
| --- | --- |
| 过冷度 | 非均匀形核所需过冷度小于均匀形核 |
| 润湿角 | 润湿角越小（越易润湿），形核体积越小，形核率越高 |
| 杂质表面形貌 | 凹面比平面、凸面更容易形核 |
| 物理因素 | 液相宏观流动、施加电磁场会提高形核率 |

## 6.6 晶体的生长

### 液固界面的微观结构

| 界面类型 | 结构特征 | 别称 | 典型材料 |
| --- | --- | --- | --- |
| 光滑界面 | 原子排列规则且相互平行，界面截然分明 | 小平面界面、结晶学界面 | 无机材料与亚金属，如 Bi、Ga、Si、As |
| 粗糙界面 | 几个原子层厚度内液固两相原子各占一半位置，原子排列混乱 | 非小平面界面 | 金属，如 Fe、Al、Cu、Ag |

### 长大机制

**【易错】这一处极易记反，注意方向**

| 界面类型 | 长大方式 | 原因 |
| --- | --- | --- |
| **粗糙界面** | **垂直长大** | 界面上留下许多空位"虚位以待"，液相原子直接填入，界面垂直于自身方向快速推进 |
| **光滑界面** | **横向长大** | 界面空位少，原子不易牢固结合，需靠二维晶核（或螺旋位错）逐层铺展 |

记忆方法：**粗糙 = 好填 = 垂直长大（快）；光滑 = 难填 = 横向长大（慢）**。

### 长大形态

取决于界面结构类型与液相温度分布，主要有**平面状长大**与**树枝状长大**两种。

## 6.7 陶瓷与聚合物的凝固结晶

- **陶瓷**：能否结晶与正负离子半径比、离子配位数、化学组成有关；
- **聚合物**：与近程、远程结构有关。

**高分子结晶度的测量方法**：X 射线衍射法、差示扫描量热法（DSC）。

# 第七章 材料的扩散与迁移

> 本章是计算题的来源之一（第一定律），概念部分以简答为主。

## 7.1 扩散的定义与成因

- **定义**：材料内部原子运动的一种方式，是固态物质中质点运动的主要形式。
- **成因**：材料在一定温度下总存在一定数量的空位，为空位扩散提供了通道。

## 7.2 Fick 定律

**【补充】Fick 第一定律（计算题的来源）**

$$J = -D\frac{\mathrm{d}C}{\mathrm{d}x}$$

其中 J 为扩散通量，D 为扩散系数，dC/dx 为浓度梯度，负号表示扩散方向与浓度梯度方向相反（由高浓度向低浓度）。

**【补充】Fick 第二定律**

$$\frac{\partial C}{\partial t} = D\frac{\partial^2 C}{\partial x^2}$$

它是质量守恒与第一定律结合的结果，用于求解浓度随时间与位置的变化，需要给出定解条件。

**【考点】** 只要求掌握第一定律的计算（难度参照课堂例题）；**第二定律只考定义，不考计算**。

## 7.3 Kirkendall 效应

- **定义**：两组元因扩散速度不同，引起标记面发生漂移的现象。
- **物理实质**：原始的扩散界面发生了移动。
- **意义**：否定了固溶体扩散的换位机制，为空位扩散机制提供了实验证据。

## 7.4 扩散的微观机制

| 机制 | 发生条件 | 说明 |
| --- | --- | --- |
| 空位扩散 | 置换固溶体 | 节点原子跃迁到相邻空位，留下新空位，空位与原子反向迁移 |
| 间隙扩散 | 间隙固溶体 | 半径较小的非金属原子（H、B、C、N、O 等）在间隙间跃迁 |
| 自间隙机制 | 碱金属晶体 | 原子挤入间隙位置 |

**【补充】** 除上述机制外，历史上还提出过**换位机制**与**环形机制**，但都被 Kirkendall 效应否定。

**对应关系**：置换固溶体以空位扩散为主，间隙固溶体以间隙扩散为主。

## 7.5 扩散的驱动力与反应扩散

- **狭义驱动力**：浓度梯度（Fick 定律的直接推动力）；
- **广义驱动力**：化学位梯度——扩散的根本驱动力。

**反应扩散**：固溶体中溶质含量超过固溶度极限从而形成新相的扩散过程。合金中的实际扩散通常同时包含均匀扩散与反应扩散。

## 7.6 影响扩散的因素（关键看扩散激活能）

| 因素 | 规律 |
| --- | --- |
| 温度 | 温度升高，扩散容易进行（影响最显著） |
| 原子键力与晶体结构 | 键力越强、原子排列越紧密，扩散激活能越高，扩散越困难；晶体对称性影响扩散的方向性 |
| 固溶体类型 | 间隙扩散的激活能明显小于空位扩散 |
| 扩散组元浓度 | 浓度梯度越大，扩散越快 |
| 晶体缺陷 | 位错相当于管道，沿位错扩散更容易（浓度梯度小时尤其明显）；沿晶界扩散也比晶内快 |
| 第三组元 | 影响较复杂，可能促进也可能阻碍 |

# 第八章 固体材料的基本性能

## 8.1 材料性能的分类

力学性能、物理性能、化学性能、工艺性能。

## 8.2 金属材料的性能

### 8.2.1 力学性能的定义

| 性能 | 定义 |
| --- | --- |
| 强度 | 材料在载荷作用下抵抗塑性变形及断裂的能力 |
| 刚度 | 材料在载荷作用下抵抗弹性变形的能力 |
| 硬度 | 材料抵抗硬物压入表面的能力 |
| 冲击韧性 | 材料在冲击载荷作用下吸收塑性变形功与断裂功的能力 |
| 断裂韧性 | 含裂纹材料抵抗快速失稳断裂的能力 |

### 8.2.2 拉伸试验与应力-应变曲线

**可得到的性能指标**：弹性模量、屈服强度、抗拉强度、延伸率、断面收缩率。

**【补充】应力-应变曲线的四个阶段与关键点**

| 阶段 | 特征 |
| --- | --- |
| 弹性变形阶段 | 应力与应变成正比（直线段），卸载后变形完全恢复 |
| 屈服变形阶段 | 曲线出现屈服平台，对应的应力为屈服强度 |
| 塑性变形阶段 | 应力继续上升直至最高点，材料发生均匀塑性变形 |
| 失稳断裂阶段 | 出现颈缩，应力下降直至断裂 |

**关键点**：弹性极限点、屈服点、最大应力点（抗拉强度）。

弹性变形与塑性变形的区别：弹性变形可完全恢复，塑性变形不可恢复。

**安全设计准则**：许用应力 = 屈服强度 / 安全系数。

### 8.2.3 断口

| 断裂类型 | 宏观特征 | 微观特征 |
| --- | --- | --- |
| 韧性断裂 | 断口呈纤维状、灰暗色，有剪切唇 | 韧窝 |
| 脆性断裂 | 断口平齐、呈结晶状、有金属光泽 | 解理台阶、河流花样 |

### 8.2.4 硬度

常见硬度测试法分三类：压痕法、回跳法、刻痕法。

| 硬度 | 压头与测量方式 | 适用说明 |
| --- | --- | --- |
| 布氏硬度 HB | 淬火钢球压头，测量**压痕直径**并计算压痕表面积 | 主要用于退火态钢铁、铸铁及有色金属，适用于 HB < 450 |
| 洛氏硬度 HR | 金刚石圆锥或钢球压头，测量**压入深度** | 压入较深，**不适合薄层与表面硬化层** |
| 维氏硬度 HV | 金刚石正四棱锥压头，测量压痕对角线长度 | 压痕小，**适合薄层与微小区域** |
| 显微硬度 | 特殊的小载荷维氏硬度 | 用于精密测定小范围区域 |
| 努氏硬度 | 测定方法类似维氏 | — |
| 邵氏硬度 | 使用压针 | 常用于高分子材料 |
| 肖氏硬度 | 回跳法 | — |
| 莫氏硬度 | 划痕法 | 常用于矿物 |

**【易错】** 布氏硬度测的是压痕**直径**（不是半径）；洛氏与维氏的适用场合相反，维氏适合薄层，洛氏不适合。

### 8.2.5 冲击韧性

材料在冲击载荷下吸收塑性变形功与断裂功的能力。

### 8.2.6 疲劳断裂

- **定义**：材料在远低于屈服应力的交变载荷作用下发生的低应力脆性断裂；
- **断口三区**：裂纹源、裂纹扩展区、断裂区；
- **特征形貌**：裂纹扩展区呈现**海滩条带**。

### 8.2.7 蠕变

材料在恒定应力作用下，变形随时间缓慢增加的现象（高温下尤为显著）。

### 8.2.8 断裂韧性

衡量含裂纹材料抵抗快速失稳断裂的能力，符号 K_IC，单位常用 MPa·m^(1/2)。

### 8.2.9 ~ 8.2.11 物理、化学与工艺性能

- **物理性能**：电学、磁学、热学、光学性能等（能举例说明即可）。
- **化学性能**：重点是耐腐蚀性，分为化学腐蚀、电化学腐蚀、物理腐蚀三类；与抗氧化性合称**化学稳定性**。
- **工艺性能**：铸造性、锻造性、热处理性（主要是淬透性）等，了解即可。

## 8.3 高分子材料的性能

### 力学状态

**线型非晶态高分子**（重点）：

玻璃态 →（玻璃化转变温度 T_g）→ 高弹态 →（粘流温度 T_f）→ 粘流态

| 类型 | 力学状态 |
| --- | --- |
| 线型晶态高分子（分子量一般） | 晶态、粘流态 |
| 线型晶态高分子（分子量较高） | 晶态、高弹态、粘流态 |
| 非完整晶态高分子 | 玻璃态、高弹态、粘流态 |
| 体型高分子（交联度小） | 玻璃态、高弹态 |
| 体型高分子（交联度大） | 玻璃态 |

### 粘弹性

- **定义**：高分子的变形与时间有关，不仅取决于应力，还取决于加载速度；
- **三种表现**：蠕变、应力松弛、内耗。

### 物理化学性能的检测

差示扫描量热法（DSC）、差热分析（DTA）。

## 8.4 陶瓷材料的性能

**如何改善陶瓷的脆性**（高频简答）

1. 避免表面产生缺陷；
2. 在表面施加压应力；
3. 用纤维或颗粒进行增韧。

其余性能了解即可。

# 第九章 基础材料

## 9.1 概述

钢铁材料包括黑色金属（钢和铸铁）与有色金属。含碳量小于 2.11% 为钢，大于 2.11% 为铸铁。

## 9.2 钢铁材料的分类

| 分类依据 | 类别 |
| --- | --- |
| 化学成分 | 碳素钢、合金钢 |
| 金相组织 | 正火状态、退火状态 |
| 冶金质量 | — |
| 用途 | 结构钢、工具钢、特殊钢 |

## 9.3 钢中的杂质元素

Si、Mn、P、S、N、O、H。其中 P、S 通常为有害元素，Si、Mn 为有益元素。

## 9.4 钢号命名规则（必考）

### 普通碳素结构钢

由三部分组成：**屈服强度 Q + 数字 + 质量等级（A/B/C/D）+ 脱氧方法（F、b、Z、TZ）**。

| 部分 | 含义 |
| --- | --- |
| Q + 数字 | 屈服强度，单位 MPa，例如 Q235 |
| 质量等级 | 跟在数字后，前面加"-"；A、B 级 P、S 含量较高，C、D 级质量较好 |
| 脱氧方法 | 沸腾钢 F、半镇静钢 b、镇静钢 Z、特殊镇静钢 TZ |

质量等级对应的冲击试验要求：A 级不做冲击试验，B 级 20℃、C 级 0℃、D 级 −20℃。

例如 Q235-AF 表示屈服强度 235 MPa、A 级质量、沸腾钢。

**【补充】** 现行国家标准已简化脱氧方法的标注（如 Q235 不再要求标出 F、b、Z），但**考试按课件与当年教材的写法**。

### 优质碳素结构钢

用平均含碳量的**万分数**以两位数字表示。例如 45 钢表示平均含碳量 0.45% 的中碳钢。含锰量较高（>0.7%）时需标出 Mn。后缀规则与普通碳素结构钢相同。

### 低合金结构钢

由"数字 +（元素 + 数字）+（元素 + 数字）+ …"组成：最前面两位数字表示平均含碳量的万分数；合金元素后面的数字表示该元素的平均百分数，**低于 1.0% 时不标明数字**。

### 碳素工具钢

钢号前加 "T"，其后数字表示含碳量的**千分数**。例如 T8 表示含碳量 0.8% 的工具钢。优质碳素工具钢在钢号末位加 A。

### 合金工具钢

规则类似合金结构钢：第一位数字表示含碳量的千分数，**平均含碳量 ≥ 1.0% 时不标明数字**。

**【考点】** 钢号是固定的送分题（通常单独出一题），建议把所有常见牌号手写整理一遍强化记忆。

## 9.5 特殊性能钢

常用不锈钢牌号可结合含碳量与合金元素来判断用途，注意区分奥氏体不锈钢、马氏体不锈钢与铁素体不锈钢的基本特征。

## 9.6 铸铁

含碳量大于 2.11% 的铁碳合金。常见类型按石墨形态区分（灰口铸铁、球墨铸铁、可锻铸铁等），了解分类与用途即可。

## 9.7 有色金属

分类：铝及其合金、铜及其合金、钛及其合金、镁及其合金。
