## 一句话总结

一门"越往后越吃前面"的大课：前半学期把复变函数这套数学工具搭起来，后半学期用它去解物理方程。**它最大的特点是不能欠账——每周跟上，难度可控；一旦缺课，后面会成倍地吃力。** 另外这门课闭卷且不允许带公式表，公式的熟练度直接决定做题速度。

## 知识框架

| 板块 | 章节 | 内容 |
| --- | --- | --- |
| 复变函数 | 第 1–4 章 | 复数与解析函数 → 复变函数的积分（柯西定理、柯西公式）→ 幂级数展开（泰勒、洛朗、孤立奇点）→ 留数定理及其四类积分应用 |
| 积分变换 | 第 5–6 章 | 傅里叶级数、傅里叶积分与变换、δ 函数；拉普拉斯变换的方法、性质、反演与应用 |
| 数学物理方程 | 第 7–11 章 | 定解问题（方程导出、定解条件、方程分类、达朗贝尔公式）→ 分离变量法（含非齐次方程与冲量定理法）→ 二阶常微分方程级数解法与本征值问题 → 球函数 → 柱函数 |

**三块的关系**：复变函数是工具，积分变换是桥梁，分离变量法是主方法，球函数与柱函数是它在两种常用坐标系下的结果。

具体来说：第 1–4 章是同一套工具的四个台阶（解析 → 积分 → 级数展开 → 留数）；第 5–6 章既是复变函数的延伸，也是解偏微分方程的通用手段；第 7 章把物理问题化成"方程 + 定解条件"，第 8 章给出主方法（分离变量法），分离之后得到常微分方程，于是需要第 9 章的级数解法与本征值理论，而第 10、11 章就是这套方法在球坐标与柱坐标下的产物。

**篇幅分布**：第 7–11 章合计占全部讲义的六成左右，后半部分是这门课实打实的重心。

## 复习攻略

**第一，不要缺课，也不要指望期末突击。** 这是最核心的一条。这门课的节奏是累积的：本人在讲柱函数时缺了一次课，之后再想跟上就明显吃力。它不像有些课可以单独补某一块——前面的工具没搭好，后面的方程根本解不动。

**第二，每周把作业和笔记整理完。** 每周消化一次，一个学期的负担是平摊的；堆到期末，量会大到无法处理。

**第三，该背的公式要背。** 本人修这门课时不喜欢背公式，很多公式是在考场上现场推导的，代价是**做题速度明显比别人慢**。这门课闭卷又不能带公式表，从考试角度讲，球函数与柱函数部分的公式最好背下来，否则推导会吃掉大量时间。

**第四，课件足够详细，不必额外找资料。** 课件内容与教材基本一致；教材主要用于找题目练习、回头查知识点。

**第五，靠做题形成手感。** 留数那一部分题型很固定，题做多了自然记住——虽然事后未必能重推，但考场上够用。

## 重点分布

> **说明：这门课的资料里没有考点清单或往年题，以下判断来自课程结构，仅供参考，不代表考试范围。**

- **后半部分（第 7–11 章）是重心**：占六成篇幅，集中了全部解题方法
- **第 8–11 章是难点集中区**：分离变量法、本征值问题、球函数、柱函数
- **第 2–4 章是套路化计算**：柯西定理、泰勒与洛朗展开、留数，步骤固定，练熟即可
- **题型以计算为主**，因此"会不会推"和"推得快不快"同样重要

## 常见坑

1. **缺课**：本人在讲柱函数时缺课，之后跟上节奏明显困难。这门课的知识是累积的，缺一块会影响后面。
2. **不背公式**：闭卷 + 不能带公式表，现场推导的代价是做不完题。球函数与柱函数部分尤其如此。
3. **考前突击**：**极不推荐**。这门课适合每周推进，不适合集中突击。
4. **它是通用语言，不会立刻兑现**：后面的课程会用到这门课的知识——微分方程求解在材料物理、半导体物理里都会出现（多数是一阶方程，套指数解或三角函数解即可），而分离变量法与特殊函数是物理类课程通用的语言，等你在文献里遇到球坐标、柱坐标下的方程时会发现这些符号都是认识的。作用体现在理解而非直接套用。
