## 一句话总结

一门"**用材料专业的内容当语料**"的学术英语课。七课各讲一类材料（导论、金属、陶瓷、高分子、生物材料、纳米材料、表征方法），每课分**语法**与**词汇**两部分。期末闭卷，考词汇解释、翻译、阅读与写作；平时每次课后有小测。它的价值不止在分数——**大学里能正经、高强度练英语的机会很少，这门课能帮你找回英语阅读的手感。**

## 知识框架

### 七个单元（按材料类别组织）

| 课次 | 主题 |
| --- | --- |
| Class 1 | Introduction to Materials Science and Engineering（材料科学导论） |
| Class 2 | Metallic Materials and Alloys（金属材料与合金） |
| Class 3 | Ceramics（陶瓷） |
| Class 4 | Polymers（高分子） |
| Class 5 | Biomaterials（生物材料） |
| Class 6 | Nanoscience, Nanotechnology and Nanomaterials（纳米科学与纳米材料） |
| Class 7 | Material Characterization Methods（材料表征方法） |

### 每课的两个部分

**Part 1 Grammar**——从课文里挑出**长难句**讲语法结构，例如倒装句、*the more… the more…* 比较结构、含 *what* 的宾语从句、长句的成分划分与语序还原。

**Part 2 Phrases**——按课积累专业词汇与学术短语。词汇表按"**原词 / 动词形式 / 形容词形式 / 固定搭配**"四列组织，例如：

| 原词及翻译 | 动词形式 | 形容词形式 | 固定搭配 |
| --- | --- | --- | --- |
| manipulate v. 操作 | manipulation (n.) | manipulative (adj.) | material manipulation, nanoscale manipulation |
| alter v. 改变 | alteration (n.) | altered (adj.) | alter the microstructure |

### 两层结构（理解这门课的关键）

1. **内容层**：七类材料的英文表达——相当于把材料科学导论、材料结构与性能那些课的核心概念用英文再过一遍；
2. **技能层**：读文献、写论文需要的**语法结构**、**学术词汇**与**固定搭配**。

两者是"用专业内容训练学术英语"的关系。所以复习重点不在材料知识本身（中文课里都学过），而在**英语的表达方式**。

## 考核方式

| 项目 | 内容 |
| --- | --- |
| 期中 | **没有** |
| 平时 | **每次课结束都有小测**，内容是课本文章的**阅读理解**；平时分**主要是小测** |
| 期末 | **闭卷**；题型包括**词汇解释、翻译、阅读、写作**；**没有听力** |

## 复习攻略

**第一，平时多总结。** 这门课的内容是"每次课一点"，堆积到期末量并不小。当堂或当天把词汇与语法整理掉，期末会轻松很多。

**第二，做一份"用英语解释英语"的词汇表。** 这是本人觉得最有效的一件事：中文释义只能让你"认得"，英文释义才能让你**用得出**。而且写论文时真正卡住你的，往往不是"这个词什么意思"，而是"这个位置该用哪个词形、配哪个介词"。

**第三，词汇是这门课的主要难点。** 语法与阅读靠原有的英语基础基本能应付，但**专业词汇必须一个个过**。可以借助 AI 提问重点词语，比逐个查词典快。

**第四，考前预留半个月。** 这门课适合"每天过一点"，不适合集中在考前一两天。

**第五，别忽视课文。** 小测考的就是课文的阅读理解，期末的翻译与阅读也建立在课文之上。

## 常见坑

1. **平时不积累，全靠考前背**——这门课的词汇量不小，集中突击会很痛苦。
2. **只记中文意思，不记词形与搭配**——写作用不上。
3. **只背单词不看课文**——小测与期末的阅读部分都来自课文。
