## 一句话总结

这门课实际上是**固体物理**：从晶体学一路讲到能带、电导、超导和介电。**内容量大、概念密度高**，但考试的特点是"**每章都考、深度分层**"——核心原理与物理图像要扎实，复杂的公式推导并不要求。它和《半导体物理》可以互相印证，对后面的保研面试和科研也用得上。

## 知识框架

把固体看成「晶格 + 电子」两个子系统：

| 板块 | 章节 | 内容 |
| --- | --- | --- |
| 结构与缺陷 | 第 1、2、3 章 | 晶体学（点阵、晶向晶面、倒易空间、对称性、X 射线衍射、布里渊区）→ 结合方式（离子键、共价键、金属键、氢键、范德华键）→ 缺陷（点、线、面） |
| 晶格振动 | 第 7 章 | 一维原子链 → 声学波与光学波 → 声子 → 晶格比热（爱因斯坦模型与德拜模型）→ 热传导与热膨胀 |
| 固体电子论与电导 | 第 8、9 章 | 经典自由电子理论 → 索末菲量子理论 → 态密度与费米能级 → 布洛赫定理与能带（近自由电子近似、有效质量、紧束缚）→ 金属电导 → 超导（二流体模型、伦敦理论、GL、BCS、约瑟夫森） |
| 介电性质 | 第 10 章 | 极化与介电参数 → 介电损耗与电击穿 → 压电、热释电、铁电 |

**一句话主线**：先讲**原子怎么排**（结构），再讲**晶格怎么振**（声子），然后讲**电子处在什么状态、怎么运动**（能带、电导、超导），最后讲**电场作用下介电体怎么响应**。

**一个特点**：第 1–3 章与《材料科学导论》《材料结构与性能》重叠较多（晶体学、缺陷、介电都讲过）；第 8 章与《半导体物理》重叠。**重复不是负担，是优势**——即使忘了要回头翻，也比从零学起快得多。

## 复习攻略

**第一，抓骨架，不要从头啃到尾。** 这门课内容量大、看着处处是重点。把每章的"框架 + 核心概念 + 判据"梳理清楚，比逐页精读效率高得多。

**第二，和《半导体物理》对照着看。** 第 8 章（固体电子论）的内容与半导体物理高度重合，两边互相印证，理解会快很多。

**第三，公式以"物理意义"为主。** 这门课的计算题不难、考试又允许带计算器，重点是知道每个量在描述什么，而不是把公式背成一串符号。

**第四，平时至少跟着作业过一遍。** 本人的做法是：平时基本不听课，但**写作业的时候会把对应章节看一遍**，有空时再整理。这个最低限度的投入能保证期末不面对一整门陌生的课。

**第五，至少留半个月。**

## 考什么、不考什么

> 以下来自本人当年的实际经历，**仅供参考，不代表以后也是这样**。

**覆盖范围：每章都考。**

**当年实际出现的计算类型**：

- 结构因子
- 缺陷密度计算（指数分布形式）
- 光学波与声学波的相关公式
- 爱因斯坦模型与德拜模型的简单计算
- 态密度相关的推导与计算
- 费米分布
- 电阻率、迁移率与其他物理量的定性关系

**当年没有考到的**：

- **超导部分的各种公式**（伦敦穿透深度、GL 相干长度、BCS 能隙、约瑟夫森等）——但**超导的核心原理考了**：迈斯纳效应与零电阻、超导体的类型、各个模型的表述
- **能带计算**（近自由电子近似的推导、紧束缚的交叠积分）

**这条经验真正的价值**：我当年以为"处处是重点"，把大量时间花在超导的公式群和能带计算的推导上，结果这些都没考到。**这不代表以后不考**——它说明的是：这门课内容多、看着处处是重点，复习时更要按当年的通知去分配时间，而不是凭感觉把每一处都背下来。

## 常见坑

1. **把精力平均分配到所有细节上。** 结果是该掌握的物理图像没吃透，冷门公式背了一堆又用不上。
2. **因为"某部分可能不考"就整章放弃。** 实际是**每章都考**，只是深度不同——任何一章的**核心概念**都不能丢。
3. **硬背超导的公式群。** 性价比低；但超导的物理图像（零电阻、迈斯纳效应、两类超导体）要能说清楚。
4. **忽视它和别的课的重叠。** 第 1–3 章很多内容此前学过，快速过一遍即可，不必当新课重学。
