## 一句话总结

内容量很大、难度不算高的一门课。两部分：一部分讲**结构决定性能**（原子与晶体 + 六类性能），另一部分讲**表面与界面**（九个专题）。特点是**考点明确、背诵量大、计算题不难**。它最值得投入的地方在于：**后面很多专业进阶 II 的课程，讲的正是这里已经学过的内容**。

## 知识框架

### 第一部分 · 结构基础与六类性能（第 1 章 + 第 3–8 章）

| 章 | 主题 | 核心内容 |
| --- | --- | --- |
| 1 | 原子与晶体 | 核外电子排布与能级跃迁、化学键与典型材料、性能与化学键的关联、能带理论、晶向晶面指数、对称性与点群空间群、7 晶系与 14 种布拉菲格子、密堆积与间隙 |
| 3 | 力学性能 | 应力应变（真实 / 名义）、弹性模量与泊松比、弹性形变机制、复合材料弹性模量、塑性形变与位错、蠕变、理论强度、Griffith 微裂纹理论、奥罗万修正、断裂韧性、增韧补强 |
| 4 | 热学性能 | 热容（爱因斯坦模型 vs 德拜模型）、热膨胀机制、各类材料的导热机制、声子热导与光子热导、抗热震性 |
| 5 | 磁学性能 | 原子尺度磁性起源、八面体配位场中的高低自旋、五类磁性的磁矩理解、磁畴、抗磁性起源、直接交换作用、磁滞回线、磁铁矿 |
| 6 | 电导 | 载流子与迁移率、离子电导、电子电导机制、能带理论与掺杂（n 型 / p 型）、相关计算 |
| 7 | 介电性能 | 极化与介电常数、电极化微观机制、多相材料介电常数、介电损耗、铁电 / 压电 / 热释电、电滞回线 |
| 8 | 光学性能 | 折射反射吸收散射透射、呈色机制、发光与发光中心、稀土与过渡金属发光、红宝石激光器 |

### 第二部分 · 表面、界面与前沿专题（第 2 章，2.1–2.9）

| 节 | 主题 |
| --- | --- |
| 2.1 | 化学键与结构基础（有机与聚合物的力学状态、热转变） |
| 2.2 | 表面界面基础（表面结构、表面成分、相界、晶界） |
| 2.3 | 表面张力和表面润湿 |
| 2.4 | 表面电现象和双电层 |
| 2.5 | 表面缺陷和缺陷反应方程式 |
| 2.6 | 熔体、玻璃和非晶材料 |
| 2.7 | 碳纤维和复合材料 |
| 2.8 | 陶瓷与烧结过程 |
| 2.9 | 表面工程与表面技术 |

**两块的关系**：第一部分是"结构决定性能"的教科书式展开，每一章都是"微观结构 → 宏观性能"的对应；第二部分是"表面与界面"这个特定视角的专题展开，从表面结构讲到表面张力、表面电现象、缺陷化学，再落到具体材料体系。两块共享同一条主线，区别在于前者看体相、后者看表面。

## 考核方式

| 项目 | 内容 |
| --- | --- |
| 期中 | **没有期中考试** |
| 期末 | **闭卷，可以带计算器**；两部分**合卷考** |
| 题型 | **以简答为主**；计算题不多、也不难（比平时习题容易） |
| 平时分 | 分章习题（第 3–8 章） |
| 大作业 | 第二部分有**文献阅读报告**（课程要求，占分） |

## 复习攻略

**第一，尽早把整门课的框架梳理出来。** 这门课有 18 个小节，内容分散。本人一开始想按章节做详细笔记，做了两节就发现行不通——太细、太花时间，而且做完后面的，前面的已经忘了。后来改成**整理两份大纲**（两部分各一份），把每节内容按层次压缩成提纲，效率高很多。这两份大纲就附在本目录下。

**第二，做计划、按天推进。** 内容量大的课，不做计划很难在期末前完成复习。本人的做法是：在期末月开始之前先给每门课做整体规划，然后每天复习开始前给自己派当天的任务。

**第三，计算题靠习题练。** 平时作业就是那六份分章习题，把它们做一遍，考试的计算部分就够了——实际考试的计算题比习题还简单。

**第四，别被"背得多"吓到。** 这门课真正的负担是记忆量，好在考点明确，照着提纲背效率不低。

## 重点分布

- **第 3–8 章（六类性能）**：计算题的来源，复习要求也写得最细
- **第 2 章（2.1–2.9）**：概念与简答为主，九节内容零散但覆盖面广
- **第 1 章**：以了解为主，属于基础分

## 常见坑

1. **打算逐章做详细笔记**：太细做不完，做完了前面的也忘了。改成提纲式的大纲更实用。
2. **不做计划**：18 个小节，不排计划很难在期末前走完。
3. **把工程实例当重点**：课件里的工程案例不作为考察对象。
4. **只背不练计算**：计算题虽然不难，但力学部分的应力应变计算、介电部分的多相材料估算这类，做一遍习题才算真的会。
