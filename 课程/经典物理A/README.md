## 一句话总结

一门课装了两门课的内容：上半学期是热力学与统计物理，下半学期（或相反）是电动力学。**内容量大、概念多、计算题重**，而且热统部分的热力学函数关系十分琐碎。它和《近代物理A》由同一位老师开设，考核结构与学习方式几乎是同一套。

## 知识框架

### 板块一：电动力学（教材用郭硕鸿）

| 讲次 | 内容 |
| --- | --- |
| 数学准备 | 正交曲线坐标系（直角 / 球 / 柱）、梯度散度旋度、高斯与斯托克斯定理、δ 函数、并矢与张量 |
| 第 1 章 | 电磁现象的普遍规律：Maxwell 方程组、介质极化与磁化、边值关系、电磁场能量与动量守恒 |
| 第 2 章 | 静电场：静电标势、泊松方程、唯一性定理、**镜像法**、电多极矩 |
| 第 3 章 | 静磁场：磁矢势（库仑规范）、静磁场能、唯一性定理、磁多极矩、等效磁荷法 |
| 第 4 章 | 电磁波的传播：平面电磁波、反射与折射（Fresnel 公式）、全反射、导体中的电磁波、波导 |
| 第 5 章 | 电磁波的辐射：规范变换、达朗贝尔方程、推迟势、电偶极辐射、磁偶极与电四极辐射 |

### 板块二：热力学与统计物理（教材用汪志诚）

| 讲次 | 内容 |
| --- | --- |
| 热力学 1 | 平衡态、温度、功与热量、第一定律、焓、热容量、卡诺循环、第二定律、熵与熵增加原理 |
| 热力学 2 | 焓、自由能、自由焓、麦氏关系及其应用、气体的节流与绝热膨胀 |
| 热力学 3 | 开系基本方程、化学势、热动平衡判据、复相平衡、克拉珀龙方程、气液相变与临界点、麦克斯韦等面积法则 |
| 统计 1 | μ 空间、等概率原理、玻尔兹曼分布、热力学量的统计表达式、单原子分子理想气体、麦克斯韦分布、能量均分定理 |
| 统计 2 | 态密度、玻色分布与费米分布、三种分布的关系、量子统计的经典极限、固体热容量 |
| 统计 3 | 弱简并量子理想气体、玻色-爱因斯坦凝聚、光子气体、自由电子气体（费米能、简并压） |

**两个板块的关系**：热力学部分是从宏观唯象角度建立定律，统计物理部分是从微观角度把这些定律推出来——先"知其然"，再"知其所以然"。

## 复习攻略

**第一，不要只靠课件。** 与《近代物理A》同样的原因：课件是提纲式的，很多概念没有完整定义，直接自学很吃力。建议配一本教材，或者用网课、AI 把概念补全。

**第二，把复习课给的要求清单当作路线图。** 这门课在复习时会直接列出考试内容和要求，分成"统计物理"与"电动力学"两大块，每一块都按"概念 + 要求"两栏写。照着这份清单逐条自查，比漫无目的地翻课件高效得多。

**第三，计算题要动手。** 这门课的考试以计算为主，电动力学的静电场、静磁场、电磁波、辐射这几块都有固定的解题套路，光看不动笔没用。

**第四，往年题价值很高。** 考试题目与历年题目相似度高，务必做透。

**第五，时间至少留一个半月。** 这门课的量比《近代物理A》还大，临时抱佛脚基本不可能。

**第六，期中不要放弃。** 期中占比与期末接近，期末也不重复考期中的内容。

## 考点分布

复习课给出的考试要求，整理如下：

**统计物理**

- 计算态密度（各种能谱、各种维度）
- 确定玻色-爱因斯坦凝聚的临界温度
- 计算光子气体的能谱密度与热力学量
- 计算自由电子气体的费米能、内能、简并压

**电动力学**

- 普遍规律：真空与介质中的电磁方程及边值关系的简单应用、计算简单系统（如电磁波）的能量与能流密度
- 静电场：用唯一性定理猜解球对称静电场、用电像法求解静电场、计算简单系统的电偶极矩
- 静磁场：用唯一性定理猜解柱对称静磁场、计算磁矩、磁荷法算磁场
- 电磁波传播：掌握波的复数表示与运算、由反射折射定律与 Fresnel 公式计算反射率与折射率
- 电磁波辐射：计算电磁偶极辐射及其能流与功率

**主战场排序**：电动力学的静电场 / 静磁场 / 辐射计算题 ≈ 统计物理的态密度与量子统计 > 电磁波传播 > 热力学部分

## 常见坑

1. **热力学函数理不清**：H、S、G、F 这几个量以及它们之间的关系又碎又多，是热统部分最主要的痛点。建议单独整理一张关系图，把定义式、全微分和麦氏关系放在一起记。
2. **统计物理比热力学难**：难点在量子统计（玻色分布、费米分布、玻色-爱因斯坦凝聚、光子气体、自由电子气体）。这部分要理解"三种分布分别在什么条件下适用"，而不是背公式。
3. **并矢与张量**：电动力学准备部分有并矢与张量的内容，认真看一遍能理解就够，后续作业题目一般不会涉及；但期末出现过与电磁场张量相关的题目，属于全卷最难的层次。
4. **电动力学吃老本**：如果之前学过大学物理的电磁学部分，电动力学的前半段会轻松很多；热统则几乎没有可吃的老本，需要从头建立。
5. **期中放弃**：期中占比和期末接近，且期末不考期中内容。
