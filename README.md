# 材料物理专业 · 课程学习经验与笔记

> 这里记录我在复旦大学材料物理专业修读课程时的**学习经验、知识框架与复习思路**，希望能帮到还没修这些课的学弟学妹。
>
> 内容 = **本人学习经验 + AI 辅助整理**。课程代码、学分、开课学期以培养方案为准；考核方式与复习方法以本人实际经历为准，仅供参考，**一切以当年课程安排为准**。

## 这个仓库有什么

- `课程/`：一门课一个文件夹，`README.md` 是这门课的学习经验主文档
- `通用方法/`：不论哪门课都用得上的学习方法
- `资源与链接.md`：公开可获取的教材、论文、网课链接
