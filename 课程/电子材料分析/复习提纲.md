## 一、引论：贯穿全课的基础

### 1. 电磁辐射与光学分析法

- **粒子性**：描述个体行为，发射或吸收一个光子满足 ΔE = hν，单位 J 或 eV；**光强与光子数有关**。
- **波动性**：描述集体行为，表现为反射、折射、散射、干涉、衍射、偏振。
- **参数**：周期 T、频率 ν、波长 λ、波数 σ，以及 c = λν、σ = 1/λ。
- **电磁波谱按"能级"分区**：X 射线区对应原子内壳层能级；紫外可见区对应原子 / 分子外层电子能级；红外区对应分子振动与转动能级；微波与无线电波区对应核自旋 / 电子自旋能级。
- **光学分析法分类**：光谱法（发射、吸收、荧光）与非光谱法（旋光、折射等）。
- **两类光谱的形状**：原子光谱是**线光谱**（能级分立），分子光谱是**带光谱**（电子能级上叠加大量的振动、转动能级）。

### 2. 光谱仪的五个基本单元

**光源（激发源）→ 单色器 → 吸收池（样品室）→ 检测器 → 读出器件**

- 光源要求输出功率足够且稳定；按需要选**连续光源**（用于分子吸收光谱，即带光谱）或**锐线光源**（用于原子吸收）。
- 单色器由入射狭缝、出射狭缝、准直镜与色散器（棱镜或光栅）组成。
- 检测器：光电倍增管、半导体检测器等。

### 3. 色散与分辨率（引论里最容易考细节的一块）

**棱镜**——靠折射分光：

- 波长长的光折射率小、偏向角小。
- 角色散率 dδ/dλ：棱镜顶角越大、材料折射率越大，色散越大。
- 分辨率 R = b·dn/dλ（b 为棱镜底边长）。
- 因为 dn/dλ 随波长变化，棱镜光谱属于**非均排光谱**。

**光栅**——靠干涉 + 衍射分光：

- 光栅公式 d(sinα ± sinθ) = Kλ；多缝干涉决定谱线位置，单缝衍射决定强度分布。
- 角色散率只取决于光栅常数 d 与级次 K，与波长无关，属于**均排光谱**（优于棱镜之处）。
- 分辨率 R = K·N（级次 × 光栅刻痕总数）：光栅越宽、刻痕越密，R 越大。
- K 不同但 Kλ 相同的谱线会重叠，需用滤光片或棱镜预色散分离。

**分辨的判据**：瑞利准则——等强度两条谱线中，一条的衍射极大恰好落在另一条的第一极小上时，认为刚好能分辨。

### 4. 四条横向主线

#### （1）定性定量方法

| 方法 | 用在哪 | 要点 |
| --- | --- | --- |
| 对比法 | 定性 | 与标准样品或标准图谱比对 |
| 标准曲线法 | 定量 | 先做浓度—信号曲线，再反查 |
| 标准加入法 | 定量 | 样品基体复杂、无法配制匹配标样时使用 |
| 内标法 | 定量 | 用内标线校正激发与进样波动 |
| 相对灵敏度因子法 | 定量（AES、XPS） | **AES 用 100% Ag 作基准，XPS 用 F 1s 作基准** |

#### （2）干扰及其消除

- **来源**：物理干扰、化学干扰、电离干扰、光谱干扰、背景干扰、自吸与自蚀、试样蒸发行为差异。
- **背景校正手段**：扣空白、双谱线校正、氘灯连续光谱校正（只能校正紫外区的连续背景）、塞曼效应校正（紫外可见都能校正，但仪器复杂）、S-H 校正法。
- **实际中一定要做空白对照。**

#### （3）四个表征参量

色散率（色散能力）、分辨率（分开相邻谱线的能力）、灵敏度、检测限——这四个词经常在简答题里被放在一起比较。

#### （4）反复出现的公式

- 玻尔兹曼分布（能级上的粒子数之比）
- 电离度 α（Saha 关系）
- Lambert-Beer 定律 A = ε l c
- 谱线变宽的四种来源（见下）
- 跃迁选择定则

**谱线变宽的四种来源**：

1. **自然宽度**：由激发态寿命决定，寿命越短越宽。
2. **多普勒变宽**：由原子热运动引起，温度越高、波长越长越宽。
3. **洛伦兹（压力）变宽**：由粒子碰撞引起，是压力变宽中的主要来源。
4. **自吸变宽**：由同种元素的基态原子吸收自己发出的光引起。

## 二、原子光谱

三种原子光谱的共同点：都关心**原子价电子**的跃迁，都用于**金属元素**分析，一般是**溶液样品**，检测限在 ppm–ppb 量级。

### 1. 原子发射光谱 OES（AES）

- **概念**：原子化（分子离解）→ 激发（玻尔兹曼分布）→ 电离（电离度 α）。**波长是特征 → 定性；谱线强度与浓度有关 → 定量。**
- **跃迁**：热激发，原子在基态与激发态之间跃迁，遵守跃迁选择定则。
- **谱图特征**：线光谱；同时存在原子线与离子线；**共振线最灵敏，第一共振线最强**；谱线多。
- **装置**：激发源（电弧、火花、ICP、辉光放电）→ 分光器（棱镜、光栅）→ 检测器（光电倍增管、半导体检测器）。
- **分析方法**：定性用铁标准图谱比对；定量用标准曲线法、标准加入法、内标法。
- **应用特点**：金属元素的定性定量；**可多元素同时分析**；非金属元素灵敏度低。

### 2. 原子吸收光谱 AAS

- **概念**：原子化后测**峰值吸收**，吸收系数与基态原子数成正比；要求**发射线波长等于吸收线波长，且发射线宽度远小于吸收线宽度**（这正是要用锐线光源的原因）；A = lg(1/T) = kc，符合吸收定律。
- **跃迁**：**只有共振吸收**——因为原子原先几乎都在基态。
- **谱图特征**：吸收谱比发射谱**简单得多**（参与吸收的原子数远少于被激发的原子数）；轮廓受自然变宽、多普勒变宽、洛伦兹变宽与自吸影响。
- **装置**：锐线光源（空心阴极灯）＋原子化器（火焰 FAAS、石墨炉 GFAAS、低温原子化器）＋背景校正。
- **分析方法**：标准曲线法、标准加入法；**不需要内标法**（AAS 信号本身很稳定）。
- **应用特点**：金属元素定量；**一次只能测一种元素**；检测限 FAAS 约 ppm–ppb，GFAAS 约 ppb–ppt（火焰中杂质多，所以检测限更高）。

### 3. 原子荧光光谱 AFS

- **概念**：**基态原子光致发光**——这是它与原子发射的根本区别（发射是热致发光）；共振荧光与非共振荧光（直跃、阶跃、敏化）；按频率关系分斯托克斯荧光（荧光频率低于激发）与反斯托克斯荧光（荧光频率高于激发）。
- **跃迁**：原子化温度与原子吸收相同，目的是保证原子处于基态。
- **谱图特征**：谱线比发射线简单；符合吸收定律。
- **装置**：与吸收光谱类似；光源为锐线光源（定量）或连续光源（可定性）。
- **分析方法**：标准曲线法、标准加入法、内标法。
- **应用特点**：金属元素分析；定量为主，用连续光源时也可定性；检测限 ppm–ppb。

### 关键公式

- 玻尔兹曼分布：N₂/N₁ = (g₂/g₁)·exp(−ΔE/kT)
- 电离度：由 Saha 关系给出，温度升高与电离能降低都会使电离度增大（加入易电离元素会抑制待测元素的电离）
- Lambert-Beer：A = lg(I₀/I) = ε l c

## 三、分子光谱

三种分子光谱的共同点：都研究**分子能级**之间的跃迁，都能给出**官能团 / 结构**信息，都是**带光谱**。

### 1. 紫外—可见分光光度法 UV-Vis

- **概念**：分子电子能级跃迁（叠加振动与转动），Δν = ΔEe/h + ΔEv/h + ΔEr/h；遵守朗伯—比尔定律，一般用于**低浓度**；**吸光度有加和性**（A = Σεᵢlcᵢ）。
- **两个术语**：**生色团**——本身含不饱和键、能产生吸收的基团；**助色团**——本身不一定吸收，但能使吸收峰红移、吸收增强。
- **红移与蓝移**：共轭效应使峰红移；溶剂极性会改变峰位。
- **跃迁**：主要是 π→π* 跃迁与电荷转移跃迁；基态是成键轨道，激发态是反键轨道。
- **谱图特征**：**带光谱**、峰宽、分辨率差；谱带数与谱带轮廓体现官能团特征（定性）；A 与 c 的关系用于定量。
- **装置**：光源钨灯（可见）与氘灯（紫外）；单光束（灵敏度高、误差大）、双光束（灵敏度低、误差小）、双波长（可消除背景与基体干扰）。
- **分析方法**：定性是与标准样品比对；定量利用加和性做**多组分同时测定**。
- **应用特点**：含不饱和键的有机物、无机金属离子络合物的定性定量。

### 2. 红外光谱法 IR

- **概念**：分子振动（叠加转动）能级跃迁；按波长分区为**近红外（倍频）、中红外（基频）、远红外（转动）**；峰比紫外可见更窄、**特征性更强**。
- **跃迁**：只有**伴随偶极矩变化**的振动才产生红外吸收——所以极性基团、对称性差的基团响应强。
- **谱图特征**：横坐标是**波数 σ（cm⁻¹）**，纵坐标是吸光度或透过率。
- **装置**：红外光源＋干涉仪＋傅里叶变换（FTIR）。红外光弱，FTIR 能同时提高灵敏度、分辨率与信噪比；时域信号经傅里叶变换回到频域。
- **分析方法**：定性是与标准图谱比对；定量同样利用加和性做多组分分析。
- **应用特点**：有机与无机化合物的定性定量。

### 3. 拉曼光谱 Raman

- **概念**：**非弹性散射**（瑞利散射是弹性散射，拉曼散射有能量交换）；用**拉曼位移**（散射光与入射光的波数差）标峰；有斯托克斯线与反斯托克斯线。
- **跃迁**：跃迁到**虚能级**后再退激发，不是特征吸收。
- **谱图特征**：Stokes 线与反 Stokes 线位置对称、**正强反弱**；**非极性分子诱导偶极性好，拉曼散射强**（这一点与红外互补）；信号弱、灵敏度低，所以要用激光。
- **装置**：激光光源（可见或近红外）；散射型或 FT-Raman。
- **分析方法**：定性；定量用散射强度与浓度的关系，配合内标法。
- **应用特点**：与红外互补——**红外强的拉曼弱，红外弱的拉曼强**。

### 关键公式

- 朗伯—比尔定律：A = lg(I₀/I) = ε l c（低浓度）
- 加和性：A = Σεᵢ l cᵢ（多组分定量的基础）
- 拉曼位移：Δσ = σ₀ − σ（只与分子本身有关，与激发波长无关）

## 四、X 射线分析

### 1. X 射线基础知识

- **发展脉络**：1895 年伦琴发现 X 射线 → 1912 年劳厄证实晶体衍射 → 1913 年布拉格建立衍射公式、莫塞莱发现波长与原子序数的关系 → 1948 年第一台 X 射线荧光光谱仪。
- **布拉格定律**：2d sinθ = nλ。λ 固定时测 θ 可得 d（测晶体结构）；d 固定时测 θ 可得 λ（分光，用于元素分析）。
- **两类谱线**：连续谱 + 特征谱；**特征谱是元素分析的依据**。
- **莫塞莱定律**：1/λ = K(Z − σ)²，即波长的倒数与原子序数成二次关系——**这是 X 射线定性的基础**。
- **选择定则**：Δn ≠ 0，ΔL = ±1，ΔJ = 0 或 ±1（当 J = 0 时 ΔJ ≠ 0）。
- **谱线标识**：先写壳层（K、L、M），再写希腊字母（α、β、γ），最后写序号（1、2、3），如 CuKα₁。
- **谱线强度关系**：IK > IL > IM；Iα > Iβ > Iγ；Iα₁ > Iα₂；IKα : IKβ 约 150 : 20；IKα₁ : IKα₂ 约 2 : 1。

### 2. X 射线荧光光谱 XRF

- **概念**：X 射线激发样品，样品发射**荧光 X 射线**——**入是 X 线、出也是 X 线**。
- **跃迁**：内层电子被激发后，外层电子跃迁填补空位，释放的能量以 X 射线形式放出。
- **装置**：**WDX**（波长色散，用晶体分光，得光谱图）与 **EDX**（能量色散，无分光系统，灵敏度高 2–3 个数量级，得能谱图）。
- **分析方法**：定性靠 λ 与 Z 的对应关系；定量因**固体样品基体干扰严重**，需要标样——真正的标样，或用纯元素做相对强度法，再做 **ZAF 修正**（原子序数 Z、吸收 A、荧光 F）。
- **应用特点**：表层元素分析（可分析 C 到 U）；固体样品；检测限约 ppm；分析深度从微米到毫米量级。

### 3. 电子探针微分析 EPMA

- **概念**：**电子束激发样品、出 X 射线**（初级发射光谱：连续谱 + 特征谱）。同一次电子束与样品作用还会产生散射电子与二次电子，可用于成像（形貌）。
- **装置**：电子光学系统，束斑直径在微米量级。
- **分析方法**：定性同 XRF（λ、E 与 Z 的对应）；定量同样受基体效应影响，用 ZAF 修正。
- **应用特点**：**微区分析**（约 1 微米³）；表层元素分析；可做**点、线、面扫描**；检测限约 0.1%。

**XRF 与 EPMA 的一句话区别**：激发源不同（X 射线 vs 电子束），因此一个偏大范围成分分析、一个偏微区分析，但特征谱的原理相同。

### 关键公式

- 布拉格定律：2d sinθ = nλ
- 莫塞莱定律：1/λ = K(Z − σ)²；ν = K(Z − σ)²
- 质量吸收系数关系：μm = kλ³Z³

## 五、表面分析

### 1. 表面分析基础

- **表面**：约 10–100 Å（1–10 nm）厚的薄层，相当于 1–10 个单原子层；结构和物理化学性质与体相完全不同。
- **为什么必须超高真空**：这么薄的表面极易吸附残留气体分子。可以用"吸附一层分子所需的时间"来估算所需的真空度——真空度每提高一个量级，清洁表面的寿命就延长相应的倍数。
- **三类技术**：AES（入电子、出电子）、XPS（入 X 射线、出电子）、SIMS（入离子、出离子）。

### 2. 俄歇电子能谱 AES

- **概念**：用电子束激发，退激发时释放俄歇电子；**退激发过程不遵守选择定则**，所以俄歇跃迁的种类很多。能量公式为

  E_WXY = E_W(Z) − ½[E_X(Z) + E_X(Z+1)] − ½[E_Y(Z) + E_Y(Z+1)]

  实际测到的能量要再减去分析器的功函数：E = E_WXY − φ_A。
- **谱图特征**：**直接谱是 N–E 曲线**，**微分谱是 dN/dE–E 曲线**；微分谱的特征是**不对称、正峰小负峰大**。之所以常用微分谱，是因为俄歇信号是在很强背景上的一次弱信号。
- **装置**：电子能量分析器，常用**筒镜分析器 CMA**，特点是**高灵敏、低分辨**。
- **分析方法**：定性看峰位（直接谱）或负峰位（微分谱）；定量用峰面积（直接谱）或正负峰高（微分谱），再乘**相对灵敏度因子（以 100% Ag 为基准）**。
- **应用特点**：元素分析（Li 到 U）；表面分析（nm 量级）；微区分析（μm）；点线面扫描；配合 Ar⁺ 溅射做**深度分析**（注意**择优溅射**会破坏定量结果）；检测限约 0.1%。

### 3. X 射线光电子能谱 XPS

- **概念**：基于**光电效应**——X 射线打出内壳层电子，测其功能。能量关系为

  E_k = hν − E_b − φ

  峰位对应电子结合能，是**元素的特征**；峰强度对应浓度，用于定量。
- **两个特有概念**：**表面荷电效应**（绝缘样品表面积累电荷，使谱峰整体偏移，需要校正）；**化学位移**（同一元素在不同化学环境里结合能不同，可区分价态与结构环境）——这是 XPS 最有价值的应用。
- **谱图特征**：谱线标识写成 O1s 这样的"元素 + 壳层"形式；横轴是光电子强度 N 或 N/E，对应结合能 E_b（或动能 E_k）。
- **装置**：电子能量分析器，常用**半球分析器 CHA**，特点是**高分辨、低灵敏**（与 AES 的 CMA 正好相反）。
- **分析方法**：峰位定性、峰面积定量；操作顺序是**先测广谱、再测窄谱**；数据处理要**扣本底 + 分峰拟合**；相对灵敏度因子以 **F 1s** 为基准。
- **应用特点**：元素分析（Li 到 U，配合紫外光电子能谱可覆盖 H、He）；表面分析（< 10 nm）；配合 Ar⁺ 溅射做深度分析；**化学态分析**；检测限约 0.1%。

### 4. 二次离子质谱 SIMS

- **概念**：一次离子入射 → 级联碰撞 → 溅射 → 打出二次离子 → 质谱分析。涉及溅射产额、离子产额、二次离子产额三个概念。
- **谱图特征**：横轴是质荷比 M/e，可测正离子也可测负离子。
- **装置**：质量分析器有四极杆、磁质量分析器（高分辨）、飞行时间（TOF）；仪器形式分静态 SIMS 与动态 SIMS、离子探针与离子显微成像。
- **分析方法**：元素定性定量；由于质量分辨本领高，可以做**同位素分析**——但也因此对分辨本领有要求（例如要区分 ³⁰Si¹H 与 ³¹P，必须达到相应的质量分辨）。
- **应用特点**：元素分析（H 到 U）；表面分析（大部分只有 2–3 个原子层）；微区分析（优于 1 μm）；可做 **2D–3D 扫描与逐层分析**；**检测限最低，可达 ppb 量级**；导体、半导体、绝缘体都能测。

### 三种表面分析技术的对比

| | AES | XPS | SIMS |
| --- | --- | --- | --- |
| 入射 | 电子束 | X 射线 | 一次离子 |
| 探测 | 俄歇电子 | 光电子 | 二次离子 |
| 分析器 | CMA（高灵敏低分辨） | CHA（高分辨低灵敏） | 四极杆 / 磁 / TOF |
| 元素范围 | Li–U | Li–U（配合 UPS 可到 H、He） | H–U |
| 定量基准 | 相对灵敏度因子（Ag） | 相对灵敏度因子（F 1s） | 需标样 |
| 检测限 | 约 0.1% | 约 0.1% | 约 ppb |
| 特长 | 微区 + 深度剖析 | **化学态** | **痕量杂质与同位素** |

## 六、横向比较表（自检用）

### 1. 按"入什么、出什么"归类

| 入射 \ 出射 | 光 | 电子 | 离子 | X 射线 |
| --- | --- | --- | --- | --- |
| 光 | UV-Vis、IR、AAS | XPS | — | — |
| 热 | OES | — | — | — |
| 电子束 | — | AES | — | EPMA |
| 离子束 | — | — | SIMS | — |
| X 射线 | — | XPS | — | XRF |

### 2. 按"给什么信息"归类

- **只要成分（元素种类与含量）**：OES、AAS、AFS、XRF、EPMA、SIMS
- **要官能团与结构信息**：UV-Vis、IR、Raman
- **要化学态**：XPS（TOF-SIMS 也可给部分信息）
- **要表面与深度分布**：AES、XPS、SIMS（配合离子溅射）
- **要微区分布**：EPMA、AES、SIMS
- **要同位素**：SIMS

### 3. 检测限从高到低（越靠后越灵敏）

EPMA（约 0.1%）→ AES / XPS（约 0.1%）→ XRF（ppm）→ OES / AAS / AFS（ppm–ppb）→ SIMS（ppb 及以下）

### 4. 最容易记混的几组

| 容易混的 | 区分点 |
| --- | --- |
| OES vs AFS | 激发方式：热致发光 vs 光致发光 |
| AAS vs OES | 参与跃迁的原子数：AAS 几乎全在基态，所以谱线简单 |
| XRF vs EPMA | 激发源：X 射线 vs 电子束（后者可微区） |
| AES vs XPS | 入射粒子（电子束 vs X 射线）＋分析器（CMA vs CHA） |
| AES vs XPS 的谱线判读 | AES 用微分谱看负峰；XPS 看峰位并结合化学位移 |
| IR vs Raman | 红外要求偶极矩变化，拉曼对非极性分子更友好，两者互补 |
