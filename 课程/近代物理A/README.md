## 一句话总结

内容跨度很大的一门物理基础课：前半段是相对论，后半段从量子假设一路走到原子物理。**相对论部分基本套公式就能过，真正的难点在量子部分。** 这门课最需要注意的是它的复习方式——课件本身是提纲式的，只靠课件自学非常吃力。

## 知识框架

| 板块 | 讲次 | 内容 |
| --- | --- | --- |
| 相对论 | 1–2 | 以太与迈克耳孙-莫雷实验、两条基本假设、洛伦兹变换、同时相对性、动钟延缓、动尺收缩、四维时空与快度；四元动量、质能关系、相对论多普勒效应、孪生子佯谬 |
| 波粒二象性 | 3 | 黑体辐射与普朗克能量子、光电效应与光量子论、康普顿效应；德布罗意假设与物质波的实验验证 |
| 量子力学基础 | 5 | 波函数统计诠释、不确定关系、薛定谔方程、算符与平均值、一维定态问题（势垒贯穿、无限深势阱、谐振子）、全同粒子与交换对称性 |
| 原子物理 | 4、6、7 | 卢瑟福散射与玻尔模型、弗兰克-赫兹实验；单电子原子（自旋、自旋轨道耦合、精细结构、电偶极选择定则）；多电子原子（电子组态、壳层结构、LS 与 jj 耦合、洪特定则、塞曼效应、X 射线） |

**主线逻辑**：经典物理留下的两朵乌云 → 相对论改写时空观 → 黑体辐射与光电效应逼出量子假设 → 德布罗意把波粒二象性推广到实物粒子 → 玻尔模型是半经典的过渡 → 薛定谔方程建立真正的量子力学 → 用它解出单电子原子，再推广到多电子原子。

## 复习攻略

**第一，不要只靠课件。** 这门课的课件是提纲式的，写得很简略，很多概念只有名字没有完整定义，直接拿来自学非常吃力。建议一开始就配一本教材，或者找网课、用 AI 把概念补全——不要硬啃课件，那样只会停在"看不懂、但还是把公式背下来"的状态。

**第二，用好课件末尾的"要求"页。** 每一讲最后都有一页"要求"，按"概念"和"应用"两列列出。这就是复习范围的直接来源，可以逐条对照自查。

**第三，往年题价值很高。** 考试题目与历年题目的相似度很高，把往年题做透的收益极大。

**第四，时间至少留一个半月。** 内容量不小，尤其是量子部分，两周根本不够。

**第五，期中不要放弃。** 期中占比与期末接近，而且期末不重复考期中的内容——期中丢的分很难在期末补回来。

**第六，用习题答案核对思路。** elearning 上的习题答案适合用来确认自己是不是真的理解了，而不是做完对个答案就过。

## 考点分布

每讲末尾的"要求"页是最权威的清单，归纳起来是：

- 用不确定关系估算零点能与能级展宽
- 求解一维无限深势阱的定态、记住谐振子能级
- 波函数归一化、算符表示与力学量平均值、确定测量值的概率分布
- 两粒子体系的总波函数与能量（含交换对称性）
- 两个任意角动量的合成、磁矩与有效磁矩
- 单电子原子定态的量子数、能量与简并度（分不计 / 计入相对论修正两种）
- 电偶极跃迁选择定则
- 由电子组态确定基态、按 LS 耦合写出全部谱项、比较能量高低、算精细结构裂距之比
- 塞曼效应（正常与反常的区别）

**主战场排序**：单电子原子 ≈ 多电子原子 > 量子力学引论 > 相对论 > 波粒二象性与玻尔模型

## 常见坑

1. **相对论能过、量子过不去**：相对论部分基本是套公式，量子部分（量子力学引论那一讲）才是真正的难点，也是全课最难的地方。
2. **多电子原子停留在"会做题"**：电子组态、LS 耦合、谱项、洪特定则、塞曼效应这一块概念密度很大，很容易变成照着例题会做、换个问法就不会。我自己就停在这个层面。回头看，先花时间把物理图像想清楚，比刷题有效。
3. **指望课件把概念讲清楚**：课件里不少概念只有名字没有定义，遇到这种地方要立刻去查教材或其他资料，不要硬啃。
4. **期中放弃**：期中占比和期末接近，且期末不考期中的内容。
5. **它是底层语言，不会立刻兑现**：后面的课程会用到这门课的知识——电动力学的电磁场理论是理解器件物理的基础，原子物理的能级与跃迁是后面学各类光谱分析方法的底子，量子统计里的费米分布在半导体物理里会直接出现。但它不会立刻变成专业课的公式，作用体现在你理解器件原理、读文献的时候。
