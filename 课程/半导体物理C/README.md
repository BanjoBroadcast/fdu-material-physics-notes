## 一句话总结

半导体物理的入门课，六章串成一条完整的推理链：**材料 → 电子状态 → 载流子统计 → 输运 → 非平衡 → 器件（pn 结）**。它的特点是**重点集中、范围不铺开**，考试有计算题但难度不高。学这门课最重要的一件事是**抓住主干**——知道什么是理想情形、什么是现实情形，不要在过深的地方消耗时间。

## 知识框架

| 章 | 主题 | 本章内容 |
| --- | --- | --- |
| 1 | 晶格结构和结合性质 | 半导体材料；晶格的对称性；常见半导体的晶格结构；结合性质 |
| 2 | 半导体中的电子状态 | 基础知识；晶体中的能带；晶体中电子的运动；导电电子和空穴 |
| 3 | 电子和空穴的平衡统计 | 费米分布函数；载流子浓度对费米能级的依赖；本征载流子浓度；非本征半导体的统计；简并情形；费米能与化学势 |
| 4 | 输运现象 | 电导和霍尔效应的分析；载流子的散射；电导的统计理论 |
| 5 | 过剩载流子 | 过剩载流子及其产生和复合；过剩载流子的扩散 |
| 6 | pn 结 | pn 结及伏安特性；势垒电容和扩散电容；隧道电流；光生伏特效应；雪崩击穿和齐纳击穿 |

**六章的关系**（理解整门课的钥匙）：

1. **第一章**：半导体长什么样——晶格结构与结合性质（属于此前内容的回顾）
2. **第二章**：电子在这种周期性晶格里处于什么状态——布洛赫定理、能带、有效质量、空穴
3. **第三章**：这些状态怎么被电子占据——费米分布、载流子浓度、费米能级位置
4. **第四章**：载流子在电场下怎么运动——迁移率、散射、电导、霍尔效应
5. **第五章**：偏离平衡时（光照、注入）载流子如何产生、复合、扩散
6. **第六章**：把前面全部合起来做成一个真实器件——pn 结的伏安特性、电容、击穿与光生伏特

## 复习攻略

**第一，抓住主干。** 这是本人最想强调的一条。这门课六章是一条链，每一章都是下一章的前提；把这条链想清楚，比零散地记公式有效得多。具体说就是：**知道什么是理想情形、什么是现实情形**，以及每一章在整条链里解决什么问题。

**第二，注意这门课的边界。** 课程只涉及**杂质完全电离**的情形——不要求处理复杂情况。知道这个边界，就不会在过深的地方浪费时间。

**第三，计算需要大量的训练。** 期末的计算题难度比小测低，但这是建立在练过大量题目的基础上的——课本的例题与习题值得反复做。

**第四，用课本的例题和习题确认理解。** 本人复习时的主要做法就是看例题、做习题，用它们来检验自己是不是真懂了，而不是只读结论。

**第五，可以借助公开网课。** 这门课在网上有完整的公开课（见仓库的参考资料），课件看不明白的地方可以对照着看。另外，向学长了解这门课实际考什么，往往比闷头复习更省时间。

**第六，和《材料物理》对着学。** 两门课的**能带理论**部分高度重叠，互相印证能省不少力气。

## 重点分布

- **第三章（平衡统计）**：**如果第一次学，这是最难的一章**，也是小测直接考察的地方（状态密度、费米分布、载流子浓度、费米能级）
- **第四章（输运）**：迁移率、霍尔效应、散射——题型套路化，练熟即可
- **第六章（pn 结）**：篇幅最大，是前面全部知识的综合，含伏安特性、电容、击穿、光生伏特
- **第二章（电子状态）**：**基础不牢后面全崩**——布洛赫定理、有效质量、空穴这几个概念必须扎实
- **第五章（过剩载流子）**：复合与扩散
- **第一章**：晶格结构与结合性质，属于此前内容的回顾，快速过一遍即可

## 常见坑

1. **把第三章当成"背公式"的章节。** 它是整条链的枢纽，理解费米能级怎么随掺杂和温度移动，比记公式重要。
2. **钻得过深。** 这门课的考察到"杂质完全电离"为止，更复杂的情形不在范围内。
3. **只读课件不做题。** 这门课有计算题，例题和习题是检验理解的主要手段——计算需要大量训练。
