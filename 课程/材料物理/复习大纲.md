# 材料物理 · 复习大纲

> 这份大纲是我按课程内容重新整理的**复习索引**：按七章组织，每章给出「框架 → 核心概念 → 关键结论 → 易混点」。
> 它的作用是**帮你快速过一遍并自查**，不是课件的替代品——公式推导与例题仍需回到课件。
> 整理原则：只保留"能串起一章的骨架"和"容易混的地方"，不堆砌细节。

## 这门课的主线

把固体看成「**晶格 + 电子**」两个子系统：

| 顺序 | 章节 | 回答的问题 |
| --- | --- | --- |
| 背景 | 第 1–3 章 | 原子**怎么排**（晶体学）→ 靠什么结合（结合方式）→ 排错会怎样（缺陷） |
| 晶格 | 第 7 章 | 晶格**怎么振** → 声子 → 解释热容、热传导、热膨胀 |
| 电子 | 第 8–9 章 | 电子**处在什么状态**（能带）→ 在外场下**怎么运动**（电导、超导） |
| 响应 | 第 10 章 | 电场作用于介电体时**怎么响应**（极化、介电损耗、击穿、压电与铁电） |

一句话：**先结构，再振动，再电子，最后看外场响应。**

## 第 1 章 晶体学

> 这一章是复习性质，大部分内容在此前的课程里学过，重点是把术语和判据一次性理清。

### 1.1 晶体结构的描述

- **晶体结构 = 点阵 + 基元**（结构基元）；点阵是抽象的几何点，基元是实际原子/分子。
- **晶胞 / 单胞 / 原胞**：单胞是能反映对称性的重复单元，原胞是体积最小的重复单元；**维格纳-赛兹原胞**是以格点为中心、作所有相邻格点连线垂直平分面围出的最小多面体。
- **晶系与布拉菲格子**：7 种晶系、14 种布拉菲格子；按对称性由低到高排列。
- **密堆积**：面心立方（ccp）与六方密堆积（hcp）都是最密堆积，空间占有率 74%；体心立方 68%、简单立方 52%。

### 1.2 晶向与晶面

- **晶向指数 [uvw]**：化最小整数比；注意方向的正负号。
- **晶面指数（密勒指数）(hkl)**：取截距的倒数再化最小整数比。
- **晶面间距 d**：立方晶系 1/d² = (h²+k²+l²)/a²；正交晶系 1/d² = h²/a² + k²/b² + l²/c²。
- **韦斯晶带轴定律**：属于同一晶带的晶面 (hkl) 与晶带轴 [uvw] 满足 **uh + vk + wl = 0**。

### 1.3 倒易空间与布里渊区

- **倒格矢**由正格子基矢定义；**面心立方的倒格子是体心立方，体心立方的倒格子是面心立方**（这条常考）。
- **布里渊区**：在倒易空间中按维格纳-赛兹方法构造的原胞；最靠近原点的封闭区域是**第一布里渊区**。

### 1.4 对称性

- **点群**：旋转轴、镜面（反映）、中心对称（反演）——描述**宏观外形**与方向性。
- **空间群**：在点群基础上加入**螺旋轴**与**滑移面**——描述**微观结构**。

### 1.5 X 射线晶体学

- **劳厄方程**与**布拉格方程** 2d·sinθ = nλ 描述同一件事（前者在倒易空间、后者在实空间）。
- **爱瓦球作图法**：把衍射条件几何化。
- **原子散射因子 f** 反映单个原子的散射能力；**晶胞结构因子 F** 是晶胞内所有原子散射的叠加。
- **衍射强度 ∝ |F|²**；**F = 0 即系统消光**。
  - **点阵消光**：由点阵类型（体心、面心等）导致；
  - **结构消光**：由基元内原子的排布导致。

**【易混点】**

- 晶胞 / 单胞 / 原胞三者不是同义词，考试常让判断"哪一个体积最小、哪一个能体现对称性"。
- 点阵消光与结构消光要分清"是点阵的锅还是基元的锅"。
- 劳厄方程与布拉格方程是同一物理事实的两种表述，不要当成两个独立条件。

## 第 2 章 晶体的结合方式

> 本章内容在课件中分散出现（此前课程已学过），复习时重点记"**每种键的特点 → 对应的宏观性质**"。

### 2.1 离子键

- 作用势 = 库仑吸引 + 电子云重叠产生的排斥；平衡间距由势能极小值决定。
- **点阵能（晶格能）**：把晶体拆成自由离子所需的能量；由**马德隆常数**、离子电荷与平衡间距决定。
- **电负性**：电负性差越大，键的离子性越强。

### 2.2 共价键

- **方向性与饱和性**是共价键的两大特征；由此解释金刚石的高硬度、高熔点。

### 2.3 金属键

- 价电子为**整个晶体所共有**；无方向性、无饱和性 → 延展性好。
- **能带出现的唯象解释**：原子靠近时能级分裂并展宽成带。
- **金属固溶体**：置换固溶体、间隙固溶体；**金属间化合物**。

### 2.4 氢键与范德华键

- **氢键**：具有**方向性和饱和性**，影响熔沸点、冰的结构等。
- **范德华键**：来源于**瞬时偶极矩**之间的相互作用，是四种键中最弱的。

**【易混点】** "哪些键有方向性/饱和性"是经典问答题：共价键（都有）、氢键（都有）、离子键与金属键（都没有）。

## 第 3 章 晶体缺陷

### 3.1 分类

- **按维度**：点缺陷（零维）、线缺陷（一维）、面缺陷（二维）、体缺陷（三维）。
- **按成因**：热缺陷（空位、填隙原子）、杂质缺陷。

### 3.2 点缺陷与扩散

- **肖特基缺陷**：只形成空位，没有等量间隙原子。
- **弗兰克尔缺陷**：空位与间隙原子成对出现。
- 缺陷浓度随温度按 **n ≈ N·exp(−E/kT)** 变化（E 为缺陷形成能）。
- **扩散与缺陷运动**：填隙原子机制与空位机制；扩散系数随温度按指数规律变化，由此可反推缺陷形成能与迁移能。

### 3.3 线缺陷（位错）

- **刃位错**：有额外半原子面；滑移方向与位错线垂直；可滑移，**也可攀移**。
- **螺位错**：滑移方向与位错线平行；一般只滑移。
- **伯格斯矢量**：描述位错引起的点阵畸变；其大小与方向决定滑移方向与滑移量。
- **滑移面**：通常是密排面，滑移方向是密排方向。

### 3.4 面缺陷

- 层错、反向畴界、孪晶、晶界。
- **小角晶界与大角晶界**；小角晶界可用**位错阵列**描述，相邻位错间距 D 与位向差 θ 的关系约为 **θ ≈ b/D**。
- **重合位置点阵**用于描述大角晶界的周期性。

**【易混点】** 刃位错的滑移方向与位错线垂直、螺位错平行；只有刃位错能攀移。

## 第 7 章 晶格振动

### 7.1 从原子链到格波

- 一维单原子链：**简谐近似**（势能只保留二阶项）→ 恢复力与位移成正比。
- 一维双原子链：出现**声学波**与**光学波**两支。
  - 声学波：相邻原子**同向**振动（长波极限对应整体平移）；
  - 光学波：相邻原子**反向**振动（长波极限下质心不动）。

### 7.2 边界条件与模式数目

- **波恩-卡门（周期性）边界条件**使波矢 q 取分立值。
- 两条重要结论：**q 的数目 = 原胞数 N**；**ω 的数目 = 原子的自由度数目**。

### 7.3 声子

- **声子**是格波能量量子化的结果，是**准粒子**（不是实物粒子）。
- 声子服从**玻色-爱因斯坦分布**；温度升高，声子数目增加。
- 量子理论下晶格振动能包含**零点能**（绝对零度时格波仍存在，但不再交换能量）。

### 7.4 晶格比热

| 模型 | 核心假设 | 结果 |
| --- | --- | --- |
| 爱因斯坦模型 | 所有原子以**同一频率**振动 | 高温趋于经典值（杜隆-珀蒂定律），低温下降过快（指数式），与实验不符 |
| 德拜模型 | 把格波看成**连续频谱**的弹性波，引入截止频率 | 高温同样趋于经典值，**低温给出 T³ 律**，与实验吻合 |

- **德拜温度 θD**：反映原子间结合力强弱与晶格"硬度"的特征温度；θD 越高，说明键越强、可用声子描述的温度范围越宽。

### 7.5 热传导与热膨胀

- **热传导的微观机理**：声子携带热量并在碰撞中传递能量；声子-声子碰撞分为**正常过程**与**倒逆过程**（倒逆过程才产生热阻）。
- **热膨胀**来源于原子间势能的**非简谐项**：简谐近似下不会出现热膨胀。

**【易混点】** 三个"简谐近似下不存在"的现象：**热膨胀**与**热传导**都需要非简谐（或声子间相互作用）才能出现；而**零点能**即使在绝对零度也存在。

## 第 8 章 固体电子论

> 全课篇幅最大、概念最密的一章。建议按"经典 → 量子 → 能带"三段来看。

### 8.1 经典自由电子理论（特鲁德-洛伦兹）

- 四条基本假设：独立电子、自由电子、碰撞（只与原子实碰撞）、**弛豫时间近似**。
- 成就：推出欧姆定律、解释热导与电导的关系。
- 问题：**无法解释电子比热**、平均自由程估计不合理。

### 8.2 索末菲量子理论

- 电子在无限深势阱中；两种边界条件对应两套解，其中周期性边界条件便于计数。
- **k 空间的量子化**：k 取分立值，每个状态在 k 空间占据固定体积。
- **态密度 D(E)**：单位能量间隔内的状态数；自由电子气（三维）D(E) ∝ E^(1/2)。

### 8.3 费米能级与费米面

- **费米能**：T = 0 K 时电子占据的最高能级；随电子浓度增大而升高，随温度变化很小。
- 相关量：**费米波矢 kF、费米温度 TF、费米速度 vF**。
- **电子气对热容的贡献**：只有费米面附近的电子被热激发，因此贡献与温度成正比（远小于经典预期）。

### 8.4 功函数与接触电势

- **功函数**：把电子从固体内部移到真空所需的最小能量。
- **理查孙-杜什曼公式**描述热电子发射电流与温度的关系。
- **接触势差**：两种材料接触后费米能级对齐导致的电势差。

### 8.5 能带理论

- **布洛赫定理**：周期性势场中电子波函数是"平面波 × 周期函数"的形式；它是能带理论的基础。
- **克龙尼克-潘纳模型**：一维周期性方势阱模型，用来演示能带与禁带的出现。
- **近自由电子近似**：把周期势当作微扰；在布里渊区边界发生**简并微扰**，由此**打开禁带**。
- **能带的三种表示法**：扩展能区、简约能区、周期能区（同一物理内容的不同画法）。
- **电子的速度与有效质量**：由 E(k) 的梯度与曲率决定；**有效质量为负**表示电子在电场中的加速度方向与经典直觉相反（可理解为"空穴行为"）。
- **导体、绝缘体、半导体**：由能带填充情况与禁带宽度解释。
- 三维情形：布洛赫定理的推广；体心立方与面心立方的第一布里渊区。
- **能带计算方法**：平面波法（近自由电子）、紧束缚近似（旺尼尔函数、交叠积分 J）——前者适合近自由电子、后者适合局域电子。

**【易混点】** 有效质量不是"电子变重了"，而是描述周期势场作用下电子对外场的响应；负有效质量不等于电子带负电荷。

## 第 9 章 固体的电导

### 9.1 金属电导

- 严格周期势场中电子自由程无限长 → 理想金属电阻率为零；**电阻来自对周期性的偏离**（热振动、杂质、缺陷）。
- **玻尔兹曼方程**描述非平衡分布函数；**弛豫时间 τ** 表示恢复到平衡的特征时间。
- 电导率表达式与温度关系：低温以杂质散射为主（剩余电阻），高温以**电子-声子散射**为主（电阻随温度近似线性上升）。
- **电子-声子散射的两种过程**：正常过程（N 过程）与**倒逆过程（U 过程）**，后者是高温下产生电阻的关键。

### 9.2 超导电性

- **基本特性**：**零电阻**与**迈斯纳效应**（完全抗磁性）；两者缺一不可，这也是超导体与"电阻为零的理想导体"的根本区别。
- **临界条件**：临界温度 Tc、临界磁场 Bc、临界电流 jc，三者相互关联。
- **两类超导体**：第一类只有一个临界磁场；第二类存在**混合态**（有零电阻但抗磁性不完全）。
- **二流体模型**：超导电子与正常电子共存，各占一定比例，随温度变化。
- **伦敦理论**：给出**穿透深度**的概念，解释磁场的表面穿透。
- **超导相变**：自由能、熵、比热在 Tc 处的变化——比热出现跳变，说明是二级相变。
- **金兹堡-朗道理论**：引入**序参量**与**相干长度**，可解释混合态与磁通量子化。
- **同位素效应**：Tc 与同位素质量有关 → 提示与晶格振动（声子）相关。
- **BCS 理论**：**电子-声子相互作用**使两个电子形成**库伯对**，配对导致**超导能隙**，这是超导的微观机制。
- **约瑟夫森效应**：直流与交流两种，是超导量子器件的基础。

**【易混点】** 迈斯纳效应 ≠ 零电阻；理想导体的磁场被"冻结"，而超导体的磁场被"排出"。

## 第 10 章 固体的介电性质

### 10.1 极化与介电参数

- **极化强度 P** 定义为单位体积内电偶极矩的矢量和；**极化率 α** 描述单个分子在单位电场下产生的电偶极矩。
- **电介质的四大参数**：电阻率、电容率（介电常数）、介电损耗角正切、抗电（击穿）强度。
- **分子极化的三种机理**：
  1. **电子极化**（正负电荷重心相对位移，频率高、响应快）；
  2. **离子极化**（正负离子相对位移）；
  3. **偶极子转向极化**（极性分子取向偏转，与温度和频率关系最强）。
- **克劳修斯方程**与**莫索提内电场**：把宏观介电常数与微观极化率联系起来。

### 10.2 自发极化与介电损耗

- **自发极化**：电滞回线、居里温度。
- **介电损耗**用**损耗角 δ** 与**损耗因子 tanδ** 描述；其来源包括**极化损耗、电导损耗、游离损耗**。
- **电击穿**：介电强度（抗电强度）；影响因素与电介质的 I-V 特性。

### 10.3 压电、热释电与铁电

| 性质 | 本质 | 与对称性的关系 |
| --- | --- | --- |
| 压电性 | 应力 ↔ 电极化的耦合 | 需要**没有对称中心**的点群 |
| 热释电性 | 温度变化引起自发极化变化 | 需要**有自发极化**（是压电性的子集） |
| 铁电性 | 自发极化可被外电场反转 | 是热释电性的子集，且存在电滞回线 |

- **铁电体**：具有**电滞回线**，关键参数为**饱和极化强度**与**剩余极化强度**；存在**铁电-顺电相变**，居里温度以上服从**居里-外斯定律**。
- **四类晶体的关系**：介电晶体 ⊃ 压电晶体 ⊃ 热释电晶体 ⊃ 铁电晶体（范围逐级缩小）。

**【易混点】** 压电性只看对称性（无对称中心），热释电性与铁电性还要求存在自发极化——所以"有压电性"不等于"有热释电性"。

## 复习建议（来自本人的实际经验）

1. **抓骨架，不要从头啃到尾。** 这门课内容量大，把每章的"框架 + 核心概念 + 判据"梳理清楚，比逐页精读效率高得多。

3. **公式以"物理意义"为主。** 这门课的计算题不难，考试也允许带计算器，重点是知道每个量在描述什么。

- 电阻率、迁移率与其他物理量的定性关系

而**超导部分的公式群**（伦敦穿透深度、GL 相干长度、BCS 能隙、约瑟夫森等）与**能带计算的推导**当年没有考到——但超导的核心原理（迈斯纳效应与零电阻、超导体的类型、各模型的表述）是考了的。
