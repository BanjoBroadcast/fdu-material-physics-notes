## 一句话总结

覆盖面很广的一门课：五章、七百多页，从固相反应动力学一路讲到高炉炼铁和塑料成型。它最需要留意的是**考试与作业之间的落差**——作业要求详细推导与方案设计，考试大部分是填空和简答。

## 知识框架

| 章 | 主题 | 内容 |
| --- | --- | --- |
| 1 | 材料制备与加工的科学基础 | 材料制备与加工的含义与分类；固相化学反应（动力学特征、动力学方程、影响因素、扬德尔方程）；相变基本原理（相图、结构特征、热力学与动力学）；烧结（扩散传质、晶粒生长、二次再结晶）；粉体；应力张量与屈服准则；塑性变形理论；流变（牛顿与非牛顿流体） |
| 2 | 无机非金属材料的制备与加工 | 粉体制备（机械粉碎、SiC 合成、溶胶-凝胶法）；成型（注浆成型、塑化剂）；烧结（热压烧结、热等静压）；玻璃的制备（辅助原料、四个阶段） |
| 3 | 高分子材料的制备与加工 | 高分子种类；聚合机理（自由基、缩合、阴离子、阳离子、配位）；聚合方法（乳液、悬浮、本体、溶液）；成型性能（熔融、流变、可加工性）；塑料成型（挤出、注射、压延、压制、二次成型）；橡胶（硫化）；纺丝 |
| 4 | 金属材料的制备与加工 | 冶金（高炉炼铁、炼钢、有色冶金）；铸造（砂型铸造、特种铸造、流动性、收缩）；压力加工（锻造、轧制、拉拔、挤压、冲压、锻造性能）；热处理（组织转变、TTT 图、退火/正火/淬火/回火/调质）；焊接（焊接冶金、接头组织、焊接工艺） |
| 5 | 薄膜材料制备与加工 | 薄膜的制备与加工 |

**各章关系**：第一章是**总论与工具箱**，讲各类材料"制备与加工"背后的共同科学基础（相变、固相反应、烧结、力学、流变）；第二、三、四章**按材料类别展开**（无机非金属 / 高分子 / 金属），都遵循"原料制备 → 成型 → 后续处理"的流程；第五章是**特殊形态**（薄膜），与前几章的块体材料相对。

## 考核方式

| 项目 | 内容 |
| --- | --- |
| 期中 | **有**；考**第一、二章** |
| 期末 | **闭卷，可以带计算器**；考**第三、四章**；**第五章不考** |
| 题型 | **以填空（20 分）和简答（80 分）为主** |
| 给分方式 | **绝对给分**：最终折算分直接换算等第，不按班级比例划档 |
| 平时分 | 作业；只要交了就有保底分 |

> 关于"绝对给分"：多数课程是相对给分（按比例划等第），这门课不是。也就是说，**拿到什么等第主要取决于你自己考得怎么样，而不是别人考得怎么样**——这一点会影响你对分数的预期。

## 复习攻略

**第一，先把考试范围搞清楚。** 老师会在考前**一两个星期**发一份**逐节的复习要点**（就在课件里）。这份东西基本就是考纲，照着它准备比什么都有效。本人当年就是对着它一条条过的。

**第二，不要按作业的风格准备考试。** 这是本篇最想提醒的一条。这门课的作业要求很高——推导扬德尔方程积分式、推导 Levy-Mises 张量的表达式、为几种陶瓷制品设计成型方法、画硫化曲线并标注阶段。但考试**大部分是填空和简答**。本人当年花了大量时间背细节，又花了大量时间看计算推导，**后来发现没必要**。

**第三，抓机制、别背细节。** 老师给复习要点时的原话是："**最重要的是原理、原因、机制，这些内容需要重点看，而一些细节性的内容可以稍微放一放。**"这句话直接决定了复习的取舍。

**第四，注意题型是填空。** 填空意味着**名词、术语、关键数字要记准**，而不是"知道个大概就行"。

**第五，考试可能有个别超纲题。**

## 考什么、不考什么

> 以下是本人当年的情况，**仅供参考**。**每年的课程安排、考试范围与侧重点都可能调整，请以当年的通知为准。**

- **期中**：第一、二章
- **期末**：第三章（约 40%）与第四章（约 60%）
- **不考**：第五章
- 期末复习要点会具体到每一节，例如：
  - 第三章：5 种经典化学聚合机理的名称、自由基与缩合聚合的基元反应、4 种聚合方法、乳液与悬浮聚合的体系组成与成粒机理、PET 的聚合工艺；熔体流动的链缠结解释、韦森堡效应与出口膨胀、入口效应；四种塑料成型方法的原理、螺杆结构、模腔压力变化；橡胶硫化的化学机理；熔融纺丝与溶液纺丝
  - 第四章：炼铁的直接与间接还原（含方程式）、炼钢任务与脱磷脱硫、铝与铜的冶炼；砂型铸造、流动性、收缩与缺陷、特种铸造；锻造性能与变形规律；加热与冷却时的组织转变（TTT、CCT 图）、退火/正火/淬火/回火/调质；焊接冶金与接头组织

## 常见坑

1. **按作业的风格复习考试。** 作业要推导、要设计，而考试以填空和简答为主——两者的准备工作差别很大。
2. **把精力花在细枝末节上。** 老师说得很清楚：细节可以放一放。
3. **忽视期中。** 第一、二章加起来三百多页，但**只在期中考**——期中之后就不必再管了。
4. **以为"交了作业就有保底分"等于容易拿高分。** 作业确实只要交了就有保底分，但最终等第由卷面直接换算（绝对给分），**想拿好成绩还是得卷面答得好**。

## 关于这门课的内容范围

这门课覆盖的是**传统材料**的制备与加工：金属（冶金、铸造、压力加工、热处理、焊接）、陶瓷与玻璃、高分子，一共五章、七百多页，从固相反应动力学一路讲到高炉炼铁和塑料成型，覆盖面很广。

有一点要说清楚：我们是材料物理专业，后面的方向大多偏电子材料与半导体，和这门课的内容**交集不算多**。所以**怎么分配这门课的精力，建议按自己的方向和实际情况来定**——这是本人学完之后的真实感受，每个人的情况不同，仅供参考。**同时提醒：每年的课程安排与考试范围都可能调整，具体情况请以当年为准。**
