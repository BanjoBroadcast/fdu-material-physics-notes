# 复旦大学材料物理专业课程学习经验与笔记

> 这里记录我在复旦大学材料物理专业修读课程时的**学习经验、知识框架与复习思路**，希望能帮到还没修这些课的学弟学妹。
>
> 内容 = **本人学习经验 + AI 辅助整理**。课程代码、学分、开课学期以培养方案为准；考核方式与复习方法以本人实际经历为准，仅供参考，**一切以当年课程安排为准**。

## 这个仓库有什么

- `课程/`：一门课一个文件夹，`README.md` 记录这门课的学习经验；部分课程会附上我自己整理的笔记
- `资源与链接.md`：各门课的教材、参考书与网课链接
- `通用方法/`：不论哪门课都用得上的学习方法

## 关于资料

这个仓库**不搬运课程资料**：课件与讲义由任课老师直接发给大家；其余参考资料（教材、习题集、网课）网上都能搜到——讲这些内容的学校很多，公开资源足够找到。

所以这里放的是三类东西：

1. **学习经验**：每门课怎么学、怎么考、踩过哪些坑
2. **我自己整理的笔记**：只放**电子版**。手写笔记不上传——扫描件不方便校订，也无法保证没有错误；电子版可以逐条核对、随时修订，所以只有整理成电子版并校对过的课程才会附上（目前是《材料科学导论》）
3. **参考资料清单**：教材、参考书、网课链接，方便你自己去找

不提供课件、教材、习题集与往年题原卷的下载，也不放网盘链接。

## 使用建议

1. **先看"一句话总结"**：立刻知道这门课值不值得提前准备。
2. **再看"考核方式"**：决定你的时间怎么分配。
3. **最后看"复习攻略"**：按自己的节奏改造，不要照搬。
